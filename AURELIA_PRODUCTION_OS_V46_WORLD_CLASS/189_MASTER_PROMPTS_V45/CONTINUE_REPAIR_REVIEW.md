# V45 Continue / Repair / Review

## CONTINUE
读取最后COMMITTED状态与未完成生产位置；不得重启；不得重写已提交历史；从next合法位置继续。

## REPAIR
OBSERVE -> CLASSIFY -> TRACE -> EARLIEST RESPONSIBLE LAYER -> MINIMUM DELTA -> IMPACT -> RECOMPILE -> VALIDATE -> PROVE。

## REVIEW
以 Truth / Causality / Character / Relationship / Audience / Drama / Theme / World / Cinema / Continuity / Production / Evidence / Future Value 十三席审查。任何关键席位失败均不得伪装成通过。
