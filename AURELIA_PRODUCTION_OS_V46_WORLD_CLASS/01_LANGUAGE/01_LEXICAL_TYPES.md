# LEXICAL TYPES

Core identifiers:
ProjectId, ProfileId, ObjectId, RevisionId, StateId, EventId, CommandId,
TaskId, TransactionId, PackageId, ArtifactId, EvidenceId, ValidationId,
AgentId, RunId, SnapshotId.

Core semantic types:
TruthValue, Authority, SemanticDelta, Constraint, Dependency, Provenance,
ContextPacket, ProductionIR, PromptAST, Observation, Evidence, Decision.

Free text is allowed for expressive content but cannot silently carry identifiers, authority, state, or policy.
