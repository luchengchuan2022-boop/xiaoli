# Creative Decision Protocol

Use a two-pass loop:
`DIVERGE → TEST → CONVERGE → RECORD DECISION`.

Every serious alternative must state its semantic delta.

Decision record fields:
- problem;
- protected meaning;
- options;
- tradeoffs;
- rejected options and reason;
- selected option;
- expected audience effect;
- production implications;
- reversibility;
- approval.

This prevents “AI taste” from becoming invisible canon.
