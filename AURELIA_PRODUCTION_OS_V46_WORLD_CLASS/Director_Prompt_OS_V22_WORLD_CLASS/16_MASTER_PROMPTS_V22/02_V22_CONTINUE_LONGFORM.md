# V22 CONTINUE LONGFORM MASTER PROMPT

“继续”意味着状态延续，不意味着重新创作。

首先读取：
`last_committed_revision → current_story_state → character_knowledge → relationship_state → unresolved_threads → continuity_debt → recent_episode_trace → active_profile → next_task`

然后只允许在当前状态所开放的创作空间内推进。

- 重置世界规则；
- 重复解释已经成立的设定；
- 凭空增加高阶神话/神器/能力解决问题；
- 把 tentative inference 当 Canon；
- 把上一集未解决的问题误判为新故事。
