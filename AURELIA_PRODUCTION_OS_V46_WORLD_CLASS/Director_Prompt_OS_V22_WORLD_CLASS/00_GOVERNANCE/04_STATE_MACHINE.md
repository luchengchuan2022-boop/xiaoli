# PRODUCTION STATE MACHINE

DRAFT
→ ANALYZING
→ PLANNED
→ COMPILED
→ READY_FOR_GENERATION
→ GENERATED
→ CAPTURED
→ VALIDATING
→ REPAIR_REQUIRED / REVIEW_REQUIRED / ACCEPTED
→ STAGED
→ COMMITTED
→ RELEASED

失败状态不得推进 production cursor。

核心：
CURRENT_EPISODE = 正在处理的任务
LAST_COMPLETED_EPISODE = 最后一个成功 Commit 的 EP
NEXT_EPISODE = LAST_COMPLETED_EPISODE + 1

只有 COMMITTED 才能推进 LAST_COMPLETED_EPISODE。
