# V24 Change Authority Model

Authority classes: `GOVERNANCE / CANON / STATE / APPROVED_INTENT / STORY_DECISION / PRODUCTION / MODEL / OBSERVATION / PROPOSAL`.

Allowed mutation classes: `D0 expression, D1 director expression, D2 production implementation, D3 story decision, D4 canon change, D5 committed state change, D6 retcon`.
D0–D2 may be automatically compiled under task policy. D3 requires story authority. D4–D6 require explicit authorization and revalidation.
