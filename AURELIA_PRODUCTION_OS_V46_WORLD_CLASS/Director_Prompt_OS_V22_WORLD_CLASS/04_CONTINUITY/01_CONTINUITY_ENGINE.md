# CONTINUITY ENGINE

检查：
Character
Costume
Hair
Face
Age
Pose / Physical State
Prop
Location
Spatial Layout
Time
Weather
Lighting
Camera Axis
Sound
Dialogue State
Emotional State
World Rules
Unresolved Threads
Future Consequences

核心：
END_STATE = START_STATE + AUTHORIZED_DELTA

delta 可以为 0。
禁止为了“看起来有变化”伪造变化。
