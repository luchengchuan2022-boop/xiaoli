# Character Agency V31

角色行动函数：
STATE + GOAL + BELIEF + FEAR + KNOWLEDGE + RELATIONSHIP + PRESSURE + CAPABILITY → CHOICE → CONSEQUENCE

## Character Truth
角色不能只由作者目标驱动。
重大行为必须通过至少两项稳定心理依据支持，并不得违反已锁定核心特征。

## Knowledge Firewall
Character A 不能自动获得 Character B 的知识；作者知道的信息不能直接泄露给角色。

## Choice Test
每个关键选择必须记录：
- available_options
- rejected_options
- selected_option
- reason
- cost
- irreversible_effect

## Growth
成长不是“变强”，而是认知、价值、关系、行为模式或自我定义发生可追踪变化。
