# V39 — Multi-Horizon Narrative Planner

Plans across `ATOM -> EPISODE -> SEQUENCE -> ARC -> SEASON -> SERIES -> IP` without forcing all horizons into one rigid outline.

## Planning objective
Maximize meaningful dramatic value while preserving character agency, world integrity, audience comprehension, future option value, production feasibility, and identity.

## Planner principle
Near-term excitement is constrained by long-term value. A spectacular beat that consumes a high-value future possibility must declare that opportunity cost.

## Outputs
- current objective;
- legal candidate futures;
- horizon scorecard;
- unresolved branches;
- future option value;
- debt/promise effects;
- required evidence;
- recommended commitment horizon.
