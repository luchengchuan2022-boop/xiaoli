# V20 NORTH STAR — CANONICAL PRODUCTION LANGUAGE

V20 的目标不是增加更多 Prompt，而是完成一次架构收敛：

**一个事实 → 一个 Canonical Object → 一个 Authority Path → 一个 State Transition → 一个 Compiler Path → 一个 Production Package → 一个 Evidence Path**

所有自然语言 Prompt 都必须被视为 Renderer，而不是系统真相。

V20 四层：
1. CREATIVE TRUTH LAYER：作品到底是什么。
2. PRODUCTION CONTROL LAYER：现在允许发生什么。
3. COMPILATION LAYER：如何把意义编译成镜头/资产/提示词。
4. RELIABILITY LAYER：如何证明、提交、恢复、重放。

最终目标：
让人类导演、AI Agent、未来 Java Runtime 都消费同一套 Canonical Production Language（CPL），而不是各自解释 Markdown。
