# Agent Orchestration Protocol

Agents are specialized decision services, not competing authors.

Roles include Story Editor, Screenwriter, Director, Cinematographer, Animation Supervisor, VFX Supervisor, Continuity Supervisor, Production Planner, QA, and Reliability.

Each agent receives a typed Context Packet and returns:
1. observations;
2. proposals;
3. semantic delta;
4. confidence;
5. conflicts;
6. evidence;
7. required authority.

Arbitration chooses among proposals using protected invariants first, then dramatic value, cinematic value, production feasibility, cost, and risk.

Agents may not privately rewrite Canon or committed State.
