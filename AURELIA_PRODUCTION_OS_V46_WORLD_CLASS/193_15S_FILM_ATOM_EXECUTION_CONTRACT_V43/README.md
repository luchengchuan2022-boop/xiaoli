# V43 — 15s Film Atom Execution Contract

15 秒不是孤立短视频，而是长篇电影的可编排原子。

## Hard requirements
- exact_duration = 15.00s
- START_STATE 已冻结
- END_STATE = START_STATE + AUTHORIZED_DELTA
- 每个 Shot 有 purpose
- 每个关键表演有 semantic reason
- 每个镜头可追溯到 Beat
- Keyframe 与 Video Prompt 同源
- Continuity carry-in / carry-out 明确
- Production Proof 完整

## 推荐编译链
小说/章节 → 语义提取 → 戏剧单元 → 情绪轨迹 → 注意力设计 → 分镜 → 景别/构图/机位 → 运镜 → 表演/微表演 → 背景/美术 → 光色/VFX/声音 → 关键帧 → 图片提示词 → 视频提示词 → 连续性 → QA → Manifest。
