# BOUNDED AUTONOMOUS CREATIVE PLANNING V42

Agents may search, simulate, critique, plan and compile within an explicit authority boundary.

Each autonomous run declares:
- objective
- frozen inputs
- allowed creative space
- forbidden mutations
- compute/time budget
- candidate budget
- stop conditions
- escalation conditions
- commit authority

Agents MUST stop when the contract is satisfied, when uncertainty crosses a critical threshold, when dependency closure is incomplete, or when a proposed change exceeds authority.
