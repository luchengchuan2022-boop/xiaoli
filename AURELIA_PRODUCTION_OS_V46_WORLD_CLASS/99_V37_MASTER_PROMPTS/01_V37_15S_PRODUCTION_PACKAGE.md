# V37 15秒世界级动画工作生产包

## A. 语义层
- 本段在长篇中的唯一核心目的
- 起始状态
- 结束状态
- 授权 Delta
- 因果链
- 人物选择
- 关系变化
- 观众已知/相信/怀疑/期待
- Promise/Debt

## B. 戏剧层
- Attention Hook（必须来自语义，不得制造空钩子）
- Beat 节点
- Emotional trajectory
- Tension curve
- Information release
- Breath / pause
- Payoff / carry-over

## C. 电影层
每个镜头必须明确：
景别 / 构图 / 机位 / 镜头轴 / 视线 / 空间关系 / 运镜 / 焦点 / 表演 / 微表演 / 背景 / 美术 / 光线 / 色彩 / 声音 / VFX。

## D. 关键帧层
每个关键状态都必须生成可执行中文图像提示词，并携带：
角色身份锁、服装锁、环境锁、时间天气、构图、动作、表情、视线、光线、美术风格、连续性约束、负面约束。

## E. 视频层
Seedance 等模型只接收已经编译好的 Cinematic Intent。视频提示词必须描述：
时间行为、镜头行为、人物运动、微表演、环境运动、焦点变化、光影变化、节奏、结束状态。

## F. QA
- 15秒精确时长
- 语义闭合
- 因果闭合
- 人物知识合法
- 关系连续
- 视觉身份连续
- 镜头轴线连续
- Prompt/Intent一致
- 无无授权新 Lore
- 无空洞奇观
