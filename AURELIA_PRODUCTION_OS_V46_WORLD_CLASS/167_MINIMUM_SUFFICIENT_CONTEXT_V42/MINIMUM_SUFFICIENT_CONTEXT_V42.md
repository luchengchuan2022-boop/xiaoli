# MINIMUM SUFFICIENT CONTEXT COMPILER V42

The compiler does not retrieve “everything relevant”. It computes the smallest context that preserves semantic correctness for the requested task.

Pipeline:
`TASK CONTRACT → REQUIRED CLAIMS → DEPENDENCY CLOSURE → AUTHORITY FILTER → TEMPORAL FILTER → KNOWLEDGE FIREWALL → CONTINUITY LOCKS → DRAMATIC REQUIREMENTS → COMPRESSION → CONTEXT HASH → CONTEXT MANIFEST`.

Compression may summarize expression but MUST NOT remove identity, causality, authority, state transition, unresolved uncertainty, or dependencies required by the task.

A context package is invalid when its dependency closure is incomplete.
