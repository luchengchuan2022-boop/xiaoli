# V39 Java Handoff — Contract Only

Java integration is intentionally deferred. V39 freezes semantic boundaries only.

Java must implement services around typed contracts; it must not own creative truth, silently reinterpret master prompts, or become a second Canon database.

Suggested service boundaries:
`Authority / State / GraphQuery / NarrativeTwin / Planner / Arena / CanonChange / Character / Relationship / Audience / CinematicCompiler / PromptCompiler / ModelAdapter / Observation / Validation / Evidence / Recovery / ProductionPackage / LongformHealth`.
