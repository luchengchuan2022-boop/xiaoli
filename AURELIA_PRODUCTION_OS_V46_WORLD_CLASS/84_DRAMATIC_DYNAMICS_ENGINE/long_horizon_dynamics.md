# Long-Horizon Dynamics V35

Optimize across LOCAL / EPISODE / SEQUENCE / ARC / SEASON / SERIES / IP.

A locally strong beat can be rejected when it:
- collapses future options;
- prematurely resolves a high-value mystery;
- spends emotional currency without earned setup;
- forces repetitive escalation;
- damages character agency;
- creates continuity debt that cannot be paid.

Preferred objective: maximum durable story value under semantic and production constraints.
