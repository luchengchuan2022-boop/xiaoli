# CREATIVE GRAPH RUNTIME V38

V38 introduces a single typed Creative Graph as the cross-scale semantic backbone. It does not replace prior modules; it coordinates them.

## Graph domains
TRUTH / STATE / EVENT / CHARACTER / RELATIONSHIP / WORLD / PROMISE / DEBT / MOTIF / AUDIENCE / DRAMA / SEQUENCE / CINEMA / ASSET / EVIDENCE / DECISION / PRODUCTION

## Rules
1. Every node has stable identity, authority, provenance, temporal scope and lifecycle.
2. Every edge declares semantics; adjacency is never interpreted as causality by default.
3. Derived views are projections, never second truth stores.
4. Writes are append-only facts/events until an authorized transaction commits state.
5. Any cross-scale dependency must be queryable and explainable.
