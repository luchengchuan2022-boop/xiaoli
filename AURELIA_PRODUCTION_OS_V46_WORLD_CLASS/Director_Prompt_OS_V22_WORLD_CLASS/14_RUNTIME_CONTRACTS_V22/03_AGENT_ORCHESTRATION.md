# V22 Agent Orchestration Protocol

Agents are specialists operating over shared canonical objects, not independent authors maintaining private truths.

Each handoff carries:
- task ID;
- input object IDs/revisions;
- authority scope;
- context packet ID;
- proposal;
- semantic delta;
- evidence;
- unresolved questions;
- requested next action.

## Arbitration

When agents disagree, the system does not average prose. It compares protected constraints, semantic deltas, evidence, and authority. Unresolved high-risk conflict is escalated.
