# Java Runtime Boundary V21

Future Java integration should implement contracts, not reinterpret prompts.

Stable boundaries:
- TaskContract
- CanonicalObject
- ContextPacket
- SemanticDelta
- ProductionIR
- PromptAST
- AdapterCapability
- Event
- Transaction
- ArtifactManifest
- ValidationResult
- EvidenceRecord

The Java runtime must preserve IDs, revisions, authority, state transitions, and provenance exactly.
