# V39 — Autonomous Studio Review

A staged review room that behaves like a professional animation studio without pretending that agent consensus is truth.

## Review gates
1. Story Editor — necessity and structure
2. Head Writer — character/causal integrity
3. World Architect — rule integrity
4. Character Director — agency/performance
5. Animation Director — staging and motion
6. Cinematographer — composition/camera/light
7. VFX — effects discipline
8. Continuity — state/asset continuity
9. Production — feasibility/cost/risk
10. QA/Reliability — reproducibility/evidence/recovery

Each reviewer can flag, support, or abstain. Conflicts are preserved and escalated; they are not averaged away.
