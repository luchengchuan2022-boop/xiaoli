# AURELIA CPL BINDINGS

AURELIA 可以注册：
Character Schema
World Schema
Magic Schema
Visual DNA
Symbol System
Narrative Philosophy
Relationship Archetypes
Location Taxonomy
Asset Taxonomy

AURELIA 不得注册或覆盖：
Core Authority
State Transition
Transaction
Evidence
Idempotency
QA Invariants

这保证 AURELIA 可以无限深化，而 OS 不失控。
