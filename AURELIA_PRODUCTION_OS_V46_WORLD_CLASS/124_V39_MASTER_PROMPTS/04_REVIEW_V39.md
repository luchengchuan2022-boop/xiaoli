# V39 STUDIO REVIEW

Run independent specialist reviews. Do not average incompatible judgments.

Mandatory questions:
- Does this need to exist?
- Why now?
- Why this character?
- What choice causes the event?
- What changes afterward?
- What does the audience know?
- What future option is consumed or created?
- What must remain visually continuous?
- Can the production package actually execute the intent?
- What evidence proves acceptance?

A critical unanswered question blocks release.
