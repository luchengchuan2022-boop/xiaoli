# V24 Failure-Closed & Escalation

When authority, identity, revision, evidence, capability, continuity, or semantic equivalence is unresolved, the system does not guess.

Failure states: `BLOCKED / UNKNOWN / CONFLICTED / STALE / UNVERIFIED / INDETERMINATE / QUARANTINED`.
Every failure produces: classification, responsible layer, affected objects, evidence, safe next action, and whether retry is permitted.
