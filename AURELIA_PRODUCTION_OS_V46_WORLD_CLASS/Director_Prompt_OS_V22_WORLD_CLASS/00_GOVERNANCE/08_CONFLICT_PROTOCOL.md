# CONFLICT PROTOCOL

冲突不是“模型自己选一个”。

分类：
CANON_CONFLICT
STATE_CONFLICT
KNOWLEDGE_CONFLICT
TEMPORAL_CONFLICT
VISUAL_REFERENCE_CONFLICT
ASSET_VERSION_CONFLICT
PROMPT_COMPILATION_CONFLICT
MODEL_CAPABILITY_CONFLICT

处理：
DETECT → LOCALIZE → CLASSIFY → FREEZE → PROPOSE RESOLUTION → AUTHORIZE → APPLY → REVALIDATE

没有授权时：
**NO SILENT RESOLUTION**
