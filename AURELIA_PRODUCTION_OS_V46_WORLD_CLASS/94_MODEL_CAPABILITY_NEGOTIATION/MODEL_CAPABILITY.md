# MODEL CAPABILITY CONTRACT V37

## Capability dimensions
LONGFORM_CONTEXT / CHARACTER_CONSISTENCY / IMAGE_COMPOSITION / MOTION / CAMERA / TEXT_RENDERING / STYLE_CONTROL / AUDIO / TEMPORAL_CONTINUITY / JSON_OR_STRUCTURED_OUTPUT.

## Negotiation
TASK_REQUIREMENTS → CAPABILITY_REQUIREMENTS → MODEL_PROFILE → GAP_ANALYSIS → ADAPTER → EXECUTION → OBSERVATION.

## Capability gap
If a model cannot reliably express required semantics, the system may:
REPLAN / SIMPLIFY_WITHOUT_MEANING_LOSS / SPLIT_TASK / CHANGE_MODEL / REQUEST_REVIEW.

It may not silently delete important meaning to make the model succeed.

## Model result boundary
MODEL_OUTPUT is observation/evidence candidate. It is never Canon merely because the model is confident.
