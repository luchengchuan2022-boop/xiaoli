# Java Handoff Boundary V31

V31 不实现 Java。

未来 Java 必须消费稳定的 typed contracts，而不是解析自由文本来猜测状态。

建议边界：
Authority API / State API / Narrative API / Character API / Relationship API / Audience API / Compiler API / Model Adapter API / Validation API / Evidence API / Transaction API / Recovery API。

Java 不拥有 Canonical Creative Truth；它执行合同、持久化状态、管理事务、调度、验证、证据与恢复。

任何无法结构化表达的核心语义必须先在 Prompt OS 层解决，再进入 Java。
