# Boundary

Java MAY own: persistence, transactions, IDs, hashes, event logs, graph storage/indexes, scheduling, concurrency, package storage, model adapters, validation execution, recovery, observability.

Java MUST NOT become the source of creative truth. Creative truth is governed by the Canon/semantic authority model. Prompt prose is not a database schema.

The runtime boundary is:
Semantic Contract → Java Orchestration → External Model → Observation → Validation → Evidence → Authorized Commit.
