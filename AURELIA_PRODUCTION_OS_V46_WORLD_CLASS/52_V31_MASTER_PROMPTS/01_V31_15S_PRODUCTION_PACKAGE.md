# V31 — 15秒世界级动画生产包指令

输入可以是小说、章节、场景、上一 Delivery Atom 或已验证创作意图。

必须自动完成：
1. 提炼本15秒不可替代的戏剧目的
2. 确定 START_STATE 与 END_STATE
3. 选择最小充分 Beat
4. 建立人物行动与关系变化
5. 建立观众注意力与认知变化
6. 规划情绪轨迹
7. 编译电影级分镜
8. 为每个镜头确定景别、构图、机位、运镜、表演、微表演、环境、光线、声音
9. 生成关键帧规划
10. 生成中文图像提示词
11. 生成中文视频提示词
12. 生成完整负面约束
13. 生成连续性锁
14. 检查模型能力与风险
15. 输出生产清单、证据与验证结果

每个提示词必须来自上游语义对象，不得自行新增故事事实。
