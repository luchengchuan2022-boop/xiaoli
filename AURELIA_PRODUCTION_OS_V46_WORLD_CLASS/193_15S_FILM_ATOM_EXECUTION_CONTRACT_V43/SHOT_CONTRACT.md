# Shot Contract

SHOT 必须至少包含：shot_id / duration / dramatic_function / framing / camera_position / movement / composition / character_blocking / performance / micro_performance / environment / art_direction / lighting / focus / audio / keyframe_ref / motion_ref / continuity_locks / source_refs。

漂亮但没有 dramatic_function 的镜头必须 FAIL。
