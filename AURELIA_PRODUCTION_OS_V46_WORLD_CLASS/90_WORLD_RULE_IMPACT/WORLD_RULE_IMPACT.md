# WORLD RULE IMPACT V37

## Rule change contract
RULE → AUTHORITY → SCOPE → PRECONDITIONS → EFFECTS → EXCEPTIONS → EXISTING DEPENDENCIES → FUTURE DEPENDENCIES → BLAST RADIUS → MIGRATION/RETCON PLAN.

## Blast radius
Evaluate impact on:
characters, abilities, institutions, history, geography, magic/technology, relationships, previous episodes, future plans, visual language, production assets and audience understanding.

## Rule precedence
COSMOLOGY > METAPHYSICS > WORLD_RULE > SYSTEM_RULE > SOCIAL_RULE > LOCAL_RULE > CINEMATIC_CONVENTION.

A lower layer cannot silently contradict a higher layer.

## New lore gate
If a new rule is not necessary to solve a real narrative problem, it should not be introduced merely because it is interesting.
