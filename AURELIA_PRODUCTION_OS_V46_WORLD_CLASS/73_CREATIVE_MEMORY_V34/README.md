# Creative Memory V34

Memory is not a transcript archive. It is a structured continuity system.

Store durable semantic state and retrievable evidence separately.

Memory classes:
TRUTH / COMMITTED_STATE / CHARACTER_KNOWLEDGE / RELATIONSHIP_STATE / PROMISE / DEBT / FORESHADOW / MOTIF / ASSET / VISUAL_CONTINUITY / AUDIENCE_MODEL / PRODUCTION_HISTORY / EVIDENCE.

Retrieval priority = authority × causal dependency × unresolved consequence × task relevance × recency × continuity sensitivity.

Compression must preserve semantic invariants. If compression loses a critical dependency, retrieval is invalid and must fail closed.
