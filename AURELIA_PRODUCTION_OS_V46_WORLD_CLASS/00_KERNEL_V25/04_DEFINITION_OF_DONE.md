# V25 DEFINITION OF DONE

A V25 specification feature is DONE only when it has:
- explicit owner and authority
- canonical terminology
- input contract
- output contract
- state model
- transition rules
- invariants
- failure modes
- evidence requirements
- replay/recovery behavior
- version/migration policy
- at least one positive Golden Case
- at least one adversarial/negative case
- explicit Java boundary implications
- no unresolved conflict with V25 Kernel

A document that merely describes intent is not a completed contract.
