# V23 Production OS Kernel Charter

V23 is the convergence release from a prompt collection into a formal, runtime-agnostic Production Language and Kernel specification.

## North Star
**One meaning → one canonical object → one authority → one state transition → one semantic IR → one deterministic compilation path → one package → one evidence chain → one verified commit.**

## Kernel layers
1. Creative Truth
2. Canonical Object Model
3. State/Event Model
4. Context/Memory Model
5. Story/Dramatic Model
6. Cinematic/Production IR
7. Compiler/Renderer
8. Agent Orchestration
9. Production Package
10. Evidence/QA/Reliability

No profile, prompt, model, or UI layer may override the kernel.

## V23 convergence rule
V23 prefers fewer authoritative contracts over a larger number of loosely related prompts. Every legacy rule must either be adopted into V23 authority or remain reference-only.
