# Continuity Ledger V21

Continuity is maintained as explicit constraints across episodes, not by asking the model to “remember”.

Track:
- temporal order;
- spatial topology;
- character appearance;
- costume/accessories;
- physical state;
- relationship state;
- knowledge state;
- world state;
- asset versions;
- unresolved contradictions.

Every production atom declares inherited locks and local changes.
