# V23 Semantic Equivalence

Two artifacts are equivalent only when protected meaning, causal role, state transition, character knowledge, continuity obligations, and declared production constraints remain equivalent.

Textual similarity is insufficient. Visual similarity is insufficient. Model confidence is insufficient.

Equivalence classes:
- `EXACT`
- `SEMANTIC_EQUIVALENT`
- `FUNCTIONALLY_EQUIVALENT_WITH_PRESENTATION_DELTA`
- `SEMANTICALLY_DIFFERENT`
- `UNKNOWN`
