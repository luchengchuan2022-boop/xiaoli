# World Simulation V31

世界系统必须回答：规则 → 条件 → 行为 → 后果 → 痕迹。

## World Layers
1. Cosmology / metaphysics
2. civilization / institutions
3. geography / infrastructure
4. ecology / economy
5. culture / ritual / language
6. everyday behavior
7. cinematic manifestation

新增世界设定必须声明 authority、来源、依赖、影响范围与是否可逆。

禁止：
- 为制造高潮临时发明规则
- 为解释漏洞临时发明神器
- 为扩大规模无限新增大陆/神明/能力
- 让世界规则只在需要时生效

世界状态变化必须能够留下至少一种可观察痕迹，除非该规则明确规定不可观测。
