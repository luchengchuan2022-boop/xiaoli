# PRODUCTION LANGUAGE GRAMMAR

Canonical high-level form:

COMMAND := ACTOR + INTENT + TARGET + CONTEXT + AUTHORITY + EXPECTATION + OPERATION

OPERATION := CREATE | CONTINUE | COMPILE | REPAIR | REVIEW | PLAN | WRITEBACK | MIGRATE | RECOVER | RELEASE

DELTA := ADD | REMOVE | REPLACE | MOVE | RELATE | STATE_CHANGE | DERIVE | SUPERSEDE

PIPELINE := EXTRACT → RESOLVE → PLAN → COMPILE → VALIDATE → PACKAGE → PROVE → COMMIT → RELEASE

Grammar is conceptual and implementation-neutral. Concrete serialization may be JSON/YAML/etc., but semantics must remain identical.
