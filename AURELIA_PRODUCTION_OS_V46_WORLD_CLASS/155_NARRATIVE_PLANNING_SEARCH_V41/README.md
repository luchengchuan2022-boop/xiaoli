# V41 Narrative Planning + Search

Search across `ATOM → EPISODE → SEQUENCE → ARC → SEASON → SERIES → IP`.

## Candidate evaluation
Evaluate truth integrity, causal power, character agency, relationship accumulation, audience clarity, dramatic value, thematic value, visual potential, continuity cost, production cost, risk and future option value.

## Planning law
Optimize across multiple horizons. A locally exciting move can be rejected if it destroys disproportionate future story space.

## Search discipline
Generate bounded candidates, simulate consequences, eliminate illegal candidates, preserve Pareto alternatives, then select with an explicit rationale.
