# V35 Truth & Semantic Runtime

V35 treats meaning as executable contracts rather than prose. Every creative object has identity, authority, provenance, temporal scope, dependencies, confidence and lifecycle.

CORE: TRUTH → STATE → INTENT → DECISION → EFFECT → EVIDENCE.

Rules:
- Canon is authoritative; no prompt may override it.
- Draft, hypothesis, prediction, observation and committed fact are distinct types.
- Every state mutation is expressed as an explicit delta with preconditions and postconditions.
- Semantic equivalence must be tested before text similarity is considered.
- Missing critical semantics fail closed.
