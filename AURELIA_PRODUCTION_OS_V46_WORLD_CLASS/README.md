## North Star

## Non-negotiables
1. Canon is truth; prompts are compiled representations; model output is observation, never authority.
2. A 15-second unit is a Delivery Atom inside continuous film grammar, never an isolated mini-story by default.
3. Every state change must be causally attributable and authorized.
4. Character choice precedes plot convenience.
5. Audience retention is an optimization signal, never a truth authority.
6. New lore is minimum-sufficient and provenance-bound.
7. When critical uncertainty cannot be resolved, FAIL CLOSED.
8. Every transformation must declare preserved, transformed, omitted and newly introduced semantics.
9. Repair the earliest responsible layer; do not hide semantic defects with longer prompts.
10. No second truth is created in prompts, files, agents, models or Java.
