# V35 Continuity + Asset Graph

Continuity is a graph of dependencies, not a final proofreading pass.

Nodes include character identity, costume, props, location geometry, screen direction, time, weather, lighting, damage, crowd state, camera axis, eye-line, asset version and VFX state.

Edges include SAME_AS / PRECEDES / DEPENDS_ON / CAUSES / TRANSFORMS / CONSUMES / APPEARS_WITH / MUST_MATCH.
