# LONG-HORIZON FORECASTING V37

## Horizons
ATOM / EPISODE / SEQUENCE / ARC / SEASON / SERIES / IP.

## Forecast variables
future option value, promise pressure, character trajectory, relationship trajectory, world consequence, audience expectation, repetition risk, production asset reuse, reveal timing and thematic development.

## Principle
Choose actions that preserve multiple strong futures when immediate story value is similar.

## No false certainty
Forecasts are ranked hypotheses with confidence and assumptions. They are never stored as committed facts.
