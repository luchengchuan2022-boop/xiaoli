# PRODUCTION LANGUAGE PRINCIPLES

1. One semantic concept has one canonical representation.
2. Human prose is an input representation, not the runtime truth.
3. Every material mutation is expressed as an explicit Semantic Delta.
4. Every command has a typed intent and typed result.
5. State changes occur only through authorized transitions.
6. Compilation is deterministic at the structural level.
7. Model outputs are observations/artifacts, not truth.
8. Unknown is preserved as unknown.
9. Every derived artifact retains lineage.
10. Every release has evidence closure.
11. Every repair begins at the earliest responsible layer.
12. Scale is solved with graphs, indexes, retrieval and snapshots, not giant prompts.
