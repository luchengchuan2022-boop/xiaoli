# AUTHORITY / CHANGE CONTROL V42

## Authority hierarchy
1. COMMITTED_CANON
2. AUTHORIZED_STATE
3. APPROVED_DECISION
4. VERIFIED_EVIDENCE
5. CANDIDATE
6. INFERENCE
7. MODEL_SUGGESTION

Lower authority can propose changes to higher authority but cannot silently promote itself.

## Change classes
LOCAL_EXPRESSION, EPISODIC, SEQUENCE, ARC, SEASON, SERIES, IP.

Each change computes blast radius, reversibility, affected promises/debts, affected knowledge states, asset impact, production impact and future-option impact.

High-blast-radius changes require explicit review and commit authorization.
