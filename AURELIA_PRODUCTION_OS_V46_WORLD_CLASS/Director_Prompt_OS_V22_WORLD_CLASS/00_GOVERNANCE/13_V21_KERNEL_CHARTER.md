# V21 Kernel Charter

## Purpose
V21 defines the smallest authoritative kernel capable of governing a world-class AI animation Production OS. The kernel is intentionally smaller than the total creative knowledge base.

## Four truths
- Creative Truth: what the work is allowed to mean.
- Committed State: what is currently true in production continuity.
- Derived Intent: what the director/compiler decides to express now.
- Observation/Evidence: what an external model or tool actually produced or proved.

These categories are never merged merely because their text looks similar.

## Kernel law
Every production operation MUST have: task identity, authority scope, input object references, semantic delta, output references, validation result, provenance, and commit status.

## Fail-closed rule
If authority, identity, dependency, capability, state transition, or evidence is unresolved, the operation cannot be promoted to committed/released state.
