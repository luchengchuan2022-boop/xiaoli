# Decision Contract

A decision records:
`QUESTION / CURRENT_STATE / HARD_CONSTRAINTS / PROTECTED_SEMANTICS / LEGAL_SPACE / CANDIDATES / FORECAST / TRADEOFFS / OPPORTUNITY_COST / REVERSIBILITY / EVIDENCE / REVIEW / SELECTED_ACTION / RATIONALE`.

Decision priority:
1. Truth and Canon safety.
2. Causal and character integrity.
3. Long-horizon story value.
4. Audience clarity and emotional value.
5. Cinematic value.
6. Production efficiency.

Optimization signals can never outrank protected semantics.
