# V24 Unified Production IR

Unified IR is the semantic bridge from story intent to production implementation.

Layers: `StoryIR → DramaticIR → BeatIR → SceneIR → ShotIR → PerformanceIR → StagingIR → CameraIR → LightingIR → EnvironmentIR → AudioIR → VFXIR → AssetIR → ContinuityIR → ConstraintIR`.
IR nodes retain source references and semantic responsibility. Rendering may transform representation, never silently erase protected semantics.
