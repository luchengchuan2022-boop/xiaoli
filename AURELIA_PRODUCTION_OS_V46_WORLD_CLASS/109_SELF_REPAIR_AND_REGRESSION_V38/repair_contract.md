# Repair Contract

Failure loop:
`OBSERVE -> CLASSIFY -> TRACE -> EARLIEST_RESPONSIBLE_LAYER -> MINIMUM_CHANGE -> BLAST_RADIUS -> RECOMPILE -> REGRESSION -> VALIDATE`.

Failure classes include semantic, canon, state, causality, character, relationship, audience, cinematic, asset, model-capability, production, evidence and transaction failures.

A repair is rejected if it fixes the visible symptom while preserving the upstream defect.

Regression compares protected semantics, state, causal graph, promises/debts, audience model, cinematic intent, continuity and production completeness.
