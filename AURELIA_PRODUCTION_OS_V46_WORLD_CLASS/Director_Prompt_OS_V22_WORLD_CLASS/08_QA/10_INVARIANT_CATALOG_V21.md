# Invariant Catalog V21

Core invariants:
1. Canon is never silently mutated.
2. Committed State changes only through authorized transitions.
3. Character knowledge never exceeds authorized knowledge state.
4. Prompt renderer cannot invent story/world facts.
5. Protected visual identity cannot drift without explicit change.
6. Every released artifact has dependency closure and evidence.
7. Writeback is idempotent.
8. Unknown/missing/conflicted values remain explicit.
9. Unsupported capabilities are surfaced.
10. Rebuild does not create new meaning.
