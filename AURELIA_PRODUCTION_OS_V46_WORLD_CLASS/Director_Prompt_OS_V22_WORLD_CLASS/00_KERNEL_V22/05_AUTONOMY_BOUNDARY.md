# V22 Bounded Autonomy Contract

AI autonomy is bounded by authority, task scope, semantic risk, and evidence requirements.

## AI may autonomously

- retrieve authorized context;
- generate proposals;
- explore open creative space;
- compile approved intent;
- render prompts;
- run validation;
- produce diagnostics and repair proposals.

## AI may not silently

- change Canon;
- rewrite committed State;
- retcon history;
- promote model output to truth;
- hide capability gaps;
- change production policy;
- release unverified artifacts.

Autonomy can increase throughput, never authority.
