# V22 Character Performance Protocol

Character performance is authored as behavior, not adjectives.

Required reasoning where relevant:
`objective → knowledge → internal conflict → attention target → physical preparation → action → micro-reaction → recovery → consequence`

Avoid generic instructions such as “looks sad” when a concrete behavioral signal can express the same state.

Protected identity includes authorized face, hair, age feeling, proportions, costume, accessories, voice/performance language, and other profile-defined locks.
