# V21 Specification Precedence

Order of authority:
1. V21 Kernel.
2. V21 Contracts.
3. Active Creative Profile.
4. V20 material explicitly marked compatible/reference.
5. Legacy/reference material.
6. Model output.

A lower layer may propose a change to a higher layer but cannot apply it.

Every inherited rule must be classified as `ADOPTED`, `ADAPTED`, `REFERENCE_ONLY`, or `REJECTED`.

No duplicate source of truth is permitted for the same canonical fact.
