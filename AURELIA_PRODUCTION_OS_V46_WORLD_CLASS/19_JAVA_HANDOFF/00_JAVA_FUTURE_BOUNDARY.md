# FUTURE JAVA BOUNDARY

V27 is implementation-neutral.

Future Java modules should implement contracts for:
Command Gateway
Object Store
Revision Store
Event Store
State Engine
Context Compiler
Story/Drama Engine
Production IR Compiler
Prompt AST Renderer
Agent Gateway
Model Gateway
Asset Store
Package Builder
Evidence Store
Validator
Transaction Manager
Recovery/Rebuild Manager
Migration Manager
Audit/Observability.

No module may create a second truth source.
