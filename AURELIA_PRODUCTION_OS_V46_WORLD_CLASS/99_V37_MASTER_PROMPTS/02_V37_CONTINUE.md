# V37 CONTINUE PROTOCOL

用户说“继续”时：
1. 读取最新已提交状态。
2. 不从上一段文字表面续写。
3. 检索最低充分上下文。
4. 检查 Promise/Debt/Character/Relationship/Audience/World/Visual Continuity。
5. 生成至少一个合法未来候选；若存在重大分歧，进行反事实比较。
6. 选择最小必要推进。
7. 生成下一 Production Atom。
8. 运行 Self-Audit + Creative Regression。
9. 只有通过后才输出 COMMIT-READY。

若状态不足：BLOCKED。
若存在冲突：QUARANTINED。
若只是模型能力问题：CAPABILITY_GAP。
