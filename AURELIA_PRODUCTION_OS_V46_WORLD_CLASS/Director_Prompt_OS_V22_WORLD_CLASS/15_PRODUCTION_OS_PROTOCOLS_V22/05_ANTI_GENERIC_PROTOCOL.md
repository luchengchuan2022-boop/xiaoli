# V22 Anti-Generic Protocol

Before release, test for:
- replaceable character behavior;
- generic romantic beats;
- interchangeable backgrounds;
- adjective-heavy rather than behavior-specific direction;
- unexplained camera movement;
- decorative VFX without dramatic purpose;
- dialogue that only conveys information;
- emotional states without causal triggers;
- continuity-free spectacle.

Repair should introduce specificity through character knowledge, choice, physical behavior, spatial relationship, consequence, or motif—not random novelty.
