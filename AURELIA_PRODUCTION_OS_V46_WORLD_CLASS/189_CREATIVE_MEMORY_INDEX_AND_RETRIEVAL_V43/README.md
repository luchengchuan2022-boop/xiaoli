# V43 — Creative Memory Index

Memory 是对 Canon / Events / State / Graph 的索引与投影，不是第二真相源。

## Retrieval unit
claim + authority + time + dependencies + provenance + confidence + relevance + invalidation condition。

## Retrieval objective
Minimum Sufficient Context，而不是最大上下文。

检索结果必须能追溯到 authoritative source。孤立记忆不能升级为事实。
