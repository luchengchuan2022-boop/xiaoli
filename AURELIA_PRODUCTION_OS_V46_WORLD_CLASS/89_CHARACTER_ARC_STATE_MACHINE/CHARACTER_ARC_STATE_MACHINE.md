# CHARACTER ARC STATE MACHINE V37

## Transition
PRE_STATE + PRESSURE + KNOWLEDGE + CHOICE + CONSEQUENCE + REFLECTION → POST_STATE.

## Change classes
- OBSERVATION_ONLY
- TEMPORARY_SHIFT
- LEARNED_RESPONSE
- RELATIONAL_SHIFT
- BELIEF_UPDATE
- VALUE_SHIFT
- IDENTITY_SHIFT
- IRREVERSIBLE_TRANSFORMATION

## Earnedness
A significant change requires a sufficient evidence chain. Emotional intensity alone is not evidence of character development.

## Regression
Regression is legal when caused by state, pressure, fear, trauma residue, contradiction or new evidence. It is not legal as arbitrary reset for plot convenience.

## Knowledge firewall
A character cannot choose from information they do not possess unless the story explicitly establishes a legal mechanism for that knowledge.
