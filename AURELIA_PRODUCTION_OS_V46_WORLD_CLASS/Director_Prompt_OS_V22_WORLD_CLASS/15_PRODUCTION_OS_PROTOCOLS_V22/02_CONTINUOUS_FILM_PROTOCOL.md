# V22 Continuous Film Protocol

Episodes are slices of one continuous cinematic work.

The compiler must preserve:
- causal continuity;
- temporal continuity;
- spatial continuity;
- character knowledge continuity;
- relationship continuity;
- visual identity continuity;
- unresolved narrative debt;
- motif and emotional trajectory.

Episode boundaries may provide delivery boundaries but must not create artificial narrative resets unless Canon explicitly defines a reset.
