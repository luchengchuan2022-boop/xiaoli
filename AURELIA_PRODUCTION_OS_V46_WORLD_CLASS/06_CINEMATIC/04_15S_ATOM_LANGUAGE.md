# 15S DELIVERY ATOM LANGUAGE

A Delivery Atom is a production delivery boundary within continuous cinema.

Required:
start_state
dramatic_purpose
beats
shot_plan
performance_plan
visual_plan
audio_intent
end_state
authorized_delta
continuity_refs
next_expected_state.

The atom may end on setup, suspension, atmosphere, attention, emotion, or action.
END_STATE = START_STATE + AUTHORIZED_DELTA, including zero delta.
