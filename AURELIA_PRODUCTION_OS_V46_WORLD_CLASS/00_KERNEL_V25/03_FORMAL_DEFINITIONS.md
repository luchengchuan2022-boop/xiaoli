# FORMAL DEFINITIONS

Truth: an authorized statement represented by a Canonical Object.
State: the committed condition of the production world at a revision.
Observation: externally produced information not yet authoritative.
Proposal: a non-committed candidate mutation.
Decision: an authorized selection among proposals.
Delta: a typed description of semantic change.
Patch: an executable representation of an authorized delta.
IR: a typed intermediate representation used by compilers.
Artifact: a produced or derived object with lineage.
Evidence: verifiable support for a claim, result, or transition.
Release: a verified, immutable publication boundary.
Context Packet: a task-scoped projection of relevant canonical information.
Production Package: a dependency-closed, evidence-closed release graph.
