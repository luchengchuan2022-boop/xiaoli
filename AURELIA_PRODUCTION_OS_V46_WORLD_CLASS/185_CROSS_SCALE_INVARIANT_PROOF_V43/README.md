# V43 — Cross-Scale Invariant Proof

Atom、Episode、Sequence、Arc、Season、Series、IP 之间建立显式 invariant inheritance。

## 规则
低层级可以表达高层语义，但不能静默改写高层 invariant。

每个生产 Atom 必须检查：
- character identity invariant
- relationship invariant
- world-rule invariant
- promise/debt invariant
- motif/story-genome invariant
- temporal/causal invariant
- visual identity invariant
- future-option invariant

任何跨尺度冲突必须指出来源层级与 blast radius，而不是“自动融合”。
