# V45 Decision + Proof Algebra

A creative decision is a typed object:
QUESTION + CURRENT_STATE + HARD_CONSTRAINTS + PROTECTED_SEMANTICS + LEGAL_SPACE + CANDIDATES + FORECAST + TRADEOFFS + REVERSIBILITY + EVIDENCE + REVIEW + SELECTION + RATIONALE.

Generator and selector MUST be independent roles.

## Proof obligations
A candidate must prove, as applicable:
- truth compatibility
- causal sufficiency
- character earnedness
- relationship evidence
- audience reveal fairness
- world-rule compatibility
- promise/debt impact
- continuity compatibility
- cinematic function
- production feasibility
- future-option impact

## Fail closed
If a critical obligation cannot be established, status = BLOCKED or QUARANTINED, never APPROVED by confidence or aesthetics alone.
