# V35 Acceptance

PASS requires semantic, creative, cinematic, production and reliability closure.

Golden tests:
1. continue never restarts;
2. missing Canon blocks;
3. model cannot mutate truth;
4. character cannot know unknown information;
5. relationship cannot jump without causal evidence;
6. spectacle without semantic effect fails;
7. unfair reveal fails;
8. new lore without authority fails;
9. context compression losing dependency fails;
10. 15s package missing any mandatory layer fails;
11. repair traces upstream;
12. multi-agent disagreement creates one arbitrated decision, never second truth;
13. asset identity drift fails;
14. downstream prompt cannot conceal upstream error;
15. long-horizon regression catches locally optimal but globally destructive choices.
