# V40 Creative Graph Operating Model

V40 elevates the Creative Graph from a useful graph into the semantic operating model of the entire Production OS.

## Non-negotiable law
There is one semantic identity for every creative object. Views, prompts, files, model outputs, caches and reports are projections or evidence; they are never a second truth.

## Canonical object envelope
Every durable object is addressable by:
- object_id
- object_type
- authority_class
- provenance
- temporal_scope
- lifecycle
- version
- dependencies
- semantic_hash
- status

## Core object families
TRUTH, STATE, EVENT, ENTITY, RELATIONSHIP, RULE, PROMISE, DEBT, MOTIF, DECISION, PLAN, DRAMATIC_BEAT, CINEMATIC_INTENT, SHOT, KEYFRAME, PROMPT, ASSET, OBSERVATION, EVIDENCE, VALIDATION, PACKAGE.

## Graph laws
1. An edge has explicit semantics; temporal adjacency is not causality.
2. A projection cannot create truth.
3. A candidate cannot satisfy a dependency that has not been approved.
4. Deletion, replacement, supersession and retcon are typed operations, never silent overwrites.
5. Cross-scale references preserve lineage.
6. Query evaluation is read-only unless a separately authorized command is issued.
7. Every committed mutation produces an event and a new semantic state version.

## Operating loop
LOAD AUTHORITY → LOAD COMMITTED STATE → QUERY DEPENDENCY CLOSURE → PLAN → GENERATE CANDIDATES → SIMULATE → REVIEW → DECIDE → COMPILE → VALIDATE → PROVE → PACKAGE → COMMIT.
