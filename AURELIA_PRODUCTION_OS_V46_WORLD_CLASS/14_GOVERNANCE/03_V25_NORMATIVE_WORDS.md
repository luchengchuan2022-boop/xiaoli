# NORMATIVE WORDS

MUST = mandatory.
MUST NOT = prohibited.
SHOULD = default unless a documented reason exists.
SHOULD NOT = discouraged unless documented.
MAY = permitted.
UNKNOWN = not established.
PROPOSED = not committed.
OBSERVED = externally observed, not authoritative.
AUTHORIZED = permitted to execute.
COMMITTED = accepted into authoritative state.
RELEASED = frozen publication boundary.
