# V41 Character Knowledge / Belief / Memory Engine

A character is not the same thing as the world database.

Maintain separately:
- objective world truth
- character knowledge
- character belief
- character uncertainty
- memory reliability
- audience knowledge

## Knowledge firewall
A character may act only from information available to that character at the decision time, unless a Canon rule explicitly grants another mechanism.

## Memory
Memories have source, confidence, emotional salience, distortion risk and temporal origin. Later revelations cannot retroactively make an earlier character choice omniscient.

## Choice contract
`state + goal + desire + belief + knowledge + fear + relationship + pressure + capability → choice`.
The choice must have a consequence and update the character state when appropriate.
