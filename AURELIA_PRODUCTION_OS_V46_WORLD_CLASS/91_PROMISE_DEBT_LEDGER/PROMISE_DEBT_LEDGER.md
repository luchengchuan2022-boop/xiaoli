# PROMISE / DEBT LEDGER V37

## Promise types
QUESTION / FORESHADOW / RELATIONSHIP_EXPECTATION / CHARACTER_GOAL / WORLD_MYSTERY / OBJECTIVE / THEME / VISUAL_MOTIF.

## Debt types
UNPAID_PROMISE / CAUSAL_DEBT / EMOTIONAL_DEBT / INFORMATION_DEBT / RELATIONSHIP_DEBT / SETUP_DEBT / CONSEQUENCE_DEBT.

## Lifecycle
CREATED → ACTIVE → PRESSURING → PAYOFF_ELIGIBLE → PAID / TRANSFORMED / EXPIRED_WITH_REASON.

## Rule
A payoff must answer the promise actually made. A new surprise cannot be used to erase an old obligation.

## Debt budget
Long-form health must monitor accumulated unresolved debt. High debt does not always require immediate payoff; it requires deliberate management and audience expectation control.
