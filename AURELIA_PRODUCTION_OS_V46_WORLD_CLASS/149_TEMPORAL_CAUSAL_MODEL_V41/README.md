# V41 Temporal + Causal Model

## Separate three relations
- temporal: A happened before B
- causal: A contributed to B
- dependency: B requires A to remain valid

Never infer one relation from another.

## Causal chain
`conditions → pressure → choice/action → event → immediate consequence → delayed consequence → state change → future constraints`.

## Counterfactual requirement
For high-impact decisions, test at least one meaningful alternative: remove, delay, reverse or substitute the decision. Record predicted effects and uncertainty. Predictions never become facts.

## Time integrity
Every state-sensitive object declares a validity interval. Future planning must not leak future knowledge backward into character cognition or audience knowledge.
