# CONTINUE / 继续 V40

“继续”不是重新创作，不是重新解释世界，不是重新设定角色。

执行：
1. 恢复最近一次 COMMITTED STATE。
2. 恢复未完成的 Promise / Debt / Mystery / Relationship / Arc / Production Position。
3. 查询当前任务所需的最小充分上下文。
4. 找到上一个已提交生产位置。
5. 从其 END_STATE 继续。
6. 只生成当前合法创作空间内的新内容。
7. 不重复已经完成的内容。
8. 不偷偷升级能力、不偷偷改变关系、不偷偷改变世界规则。
9. 通过跨尺度与连续性验证后输出。

如果状态不足：明确指出缺失项并阻断依赖该缺失项的断言；不要猜。
