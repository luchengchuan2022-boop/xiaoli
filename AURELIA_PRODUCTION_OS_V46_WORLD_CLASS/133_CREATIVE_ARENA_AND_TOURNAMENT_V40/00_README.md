# Creative Arena V40

The Arena is a bounded competition environment for candidate creative solutions. It prevents premature convergence on the first plausible answer.

## Tournament stages
BRIEF → GENERATE → HARD-CONSTRAINT FILTER → SEMANTIC NORMALIZATION → COUNTERFACTUAL SIMULATION → ADVERSARIAL REVIEW → PARETO FRONTIER → HUMAN/AUTHORITY DECISION → COMPILE.

Candidates are compared against the same frozen context. Candidate generators cannot score their own work as final authority.
