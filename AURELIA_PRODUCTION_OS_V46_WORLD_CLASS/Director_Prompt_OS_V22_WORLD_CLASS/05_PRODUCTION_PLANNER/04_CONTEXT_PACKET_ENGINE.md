# CONTEXT PACKET ENGINE

长篇生产禁止把整个历史塞进 Prompt。

根据任务动态生成最小充分 Context Packet：

1. task context
2. authoritative canon slice
3. committed state slice
4. relevant character knowledge
5. active relationship state
6. active unresolved threads
7. relevant future consequences
8. relevant visual locks
9. relevant asset refs
10. required constraints

Context Packet 必须可追踪来源。
