# V21 Definition of Done

V21 is complete only when it can demonstrate:

- one canonical truth path;
- deterministic object identity and lineage;
- explicit semantic deltas;
- bounded context retrieval;
- causal long-form planning;
- character knowledge continuity;
- cinematic IR independent of vendor prompts;
- complete 15-second production atom compilation;
- capability-aware prompt rendering;
- dependency-closed production packages;
- event-sourced transactional writeback;
- idempotent retries and replay recovery;
- property-based and golden-case QA;
- 1600–8000 episode stress readiness;
- AURELIA profile isolation;
- Java-ready contract boundaries.

“看起来高级”不算完成；必须可验证、可回放、可诊断、可修复。
