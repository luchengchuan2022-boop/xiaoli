# V41 Self-Healing + Regression

Repair must begin at the earliest responsible semantic layer.

`OBSERVE → CLASSIFY → TRACE → ROOT CAUSE → MINIMUM DELTA → IMPACT → RECOMPILE → REGRESSION → ACCEPT`.

## Regression dimensions
Truth, causality, character, relationship, audience, drama, theme, continuity, visual identity, production completeness, evidence and future option value.

## No symptom repair
Do not repair a semantic error by changing only a downstream Prompt. If the source meaning is wrong, the prompt must not hide the defect.

## Deterministic replay
Same committed inputs + same compiler contract must reproduce the same semantic package structure and trace decisions, while pixel-level model output remains model-dependent.
