V33 Visual Identity & Continuity Graph

Treat visual identity as a graph of invariants and controlled variables.

Locks: FACE, EYES, HAIR, AGE_FEEL, PROPORTION, COSTUME, ACCESSORIES, PALETTE, MATERIAL_LANGUAGE, SILHOUETTE, ENVIRONMENT_GEOMETRY, SCALE, LIGHTING_TIME, WEATHER, SCREEN_DIRECTION, ASSET_VERSION.

Every generated image/video prompt must declare which locks are inherited, which may vary, and why.

Identity drift is a validation failure, not a style preference. Controlled variation requires explicit semantic purpose.
