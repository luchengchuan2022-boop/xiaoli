# ARCHITECTURE REVIEW

Review questions:
1. Did we create a duplicate truth source?
2. Did we add a new state machine unnecessarily?
3. Did we add a second IR for the same meaning?
4. Can this be represented by an existing contract?
5. Does it increase cognitive load more than production value?
6. Is the new behavior testable?
7. Is recovery defined?
8. Is migration defined?
9. Does it preserve theatrical creative quality?
10. Does it improve or degrade 8000-episode operability?

Default outcome should favor convergence.
