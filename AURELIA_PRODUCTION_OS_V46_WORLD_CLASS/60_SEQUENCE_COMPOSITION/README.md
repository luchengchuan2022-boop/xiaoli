V33 Sequence Composition OS

Compose scenes and delivery atoms as continuous cinematic sequences rather than isolated clips.

Sequence model: ENTRY_STATE -> EXPECTATION -> DISTURBANCE -> ESCALATION/DEEPENING -> TURN -> BREATH/AFTERMATH -> EXIT_STATE.

15-second atom is a delivery unit inside sequence continuity. It may be quiet. It must have a meaningful state relation and cannot be forced to contain a plot twist.

Track tension, intimacy, mystery, visual intensity, dialogue density, motion density, and silence as bounded curves.

Anti-filler tests: deletion, compression, substitution, repetition, emotional necessity.
