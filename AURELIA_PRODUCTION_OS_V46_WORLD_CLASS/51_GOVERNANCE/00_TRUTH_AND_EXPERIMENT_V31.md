# Truth, Experiment & Evolution Governance V31

Truth hierarchy：
1. committed canon / authority
2. committed state
3. validated evidence
4. candidate
5. model suggestion
6. inference

实验必须隔离：实验不得污染 committed truth。

Retcon 必须产生：reason / affected history / replacement truth / impacted artifacts / migration plan / approval / new revision。

冲突必须 quarantine，不能选择“看起来更酷”的一方作为真相。

每个产物必须可回答：它来自哪里？经过哪些变换？由谁/什么规则决定？验证过什么？最终是否提交？
