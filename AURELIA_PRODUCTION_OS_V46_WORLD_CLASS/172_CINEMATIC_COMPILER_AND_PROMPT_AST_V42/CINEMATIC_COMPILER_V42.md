# CINEMATIC COMPILER / PROMPT AST V42

The compiler is semantic-first. It may choose cinematic language only after dramatic purpose and performance are defined.

`MEANING → AUDIENCE FOCUS → BEAT → PERFORMANCE → BLOCKING → COMPOSITION → SHOT → CAMERA → FOCUS → LIGHT → COLOR → ENVIRONMENT → VFX → AUDIO → KEYFRAME AST → IMAGE PROMPT AST → VIDEO PROMPT AST`.

Every prompt node records semantic source and transformation status: PRESERVED / TRANSFORMED / OMITTED_WITH_REASON / INTRODUCED_AS_CINEMATIC_EXPRESSION.

Prompt wording can never authorize a semantic change upstream.
