# CHARACTER AGENCY ENGINE

角色不是剧情搬运工具。剧情必须尽可能通过角色在约束下的选择推进。

CHARACTER_STATE + GOAL + FEAR + BELIEF + KNOWLEDGE + RELATIONSHIP + PRESSURE → CHOICE → CONSEQUENCE

每次关键事件必须记录：
- actor
- available_choices
- chosen_action
- rejected_alternatives（若重要）
- motivation_evidence
- immediate_consequence
- long_term_consequence

禁止“为了剧情所以角色突然这样做”。若角色行为无法由状态解释，判定为 AGENCY_FAILURE。
