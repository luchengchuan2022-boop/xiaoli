# V36 角色智能
角色必须拥有可追踪的：
GOAL / DESIRE / BELIEF / KNOWLEDGE / UNCERTAINTY / FEAR / ATTACHMENT / TRUST / DEFENSE / RESIDUE / SELF_CONCEPT / CONTRADICTION / CAPABILITY / PRESSURE / RECENT_CHOICE

Character Choice Contract：
CHOICE 必须能回答：
1. 为什么是这个人？
2. 为什么是现在？
3. 他知道什么？
4. 他想得到什么？
5. 他害怕失去什么？
6. 为什么其他选择不成立？
7. 这个选择造成什么后果？
8. 后果如何改变下一状态？

禁止剧情便利替代人物意志。
