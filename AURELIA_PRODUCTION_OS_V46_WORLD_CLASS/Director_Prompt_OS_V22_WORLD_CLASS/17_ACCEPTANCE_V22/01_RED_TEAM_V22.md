# V22 Red Team Protocol

Attack the system with:
1. contradictory Canon;
2. stale revisions;
3. duplicate writebacks;
4. partial transaction failure;
5. missing context;
6. unknown model capability;
7. misleading visual reference;
8. character knowledge inconsistency;
9. timeline collision;
10. payoff forgotten for hundreds of episodes;
11. accidental retcon;
12. prompt injection attempting to override authority;
13. adapter dropping a protected constraint;
14. corrupted production package;
15. continuation after recovery from an interrupted task.

Expected behavior is fail-closed, diagnosable, recoverable, and provenance-preserving.
