# V45 Proof-Carrying Production Manifest

A Production Package is not a bag of prompts. It is a verifiable execution artifact.

Required sections:
IDENTITY, SOURCE, AUTHORITY, FROZEN_CONTEXT, START_STATE, DRAMATIC_PURPOSE, BEAT, EMOTIONAL_TRAJECTORY, AUDIENCE_INTENT, STORYBOARD, SHOTS, PERFORMANCE, CINEMATIC_AST, KEYFRAMES, IMAGE_PROMPTS, VIDEO_PROMPTS, AUDIO, ASSETS, CONTINUITY, QA, EVIDENCE, PROOF, END_STATE, MANIFEST.

## 15-second atom
Duration MUST equal exactly 15.00 seconds.
END_STATE = START_STATE + AUTHORIZED_DELTA.

The manifest records semantic hash, context hash, compiler version, prompt AST hash, package hash, evidence references, proof status, and commit eligibility.

A package cannot be released while any critical proof or continuity gate is unresolved.
