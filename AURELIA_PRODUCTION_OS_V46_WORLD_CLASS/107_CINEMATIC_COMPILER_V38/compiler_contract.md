# Compiler Contract

`MEANING -> AUDIENCE_FOCUS -> PERFORMANCE -> STAGING -> COMPOSITION -> CAMERA -> LIGHT -> SOUND -> KEYFRAME -> IMAGE_PROMPT -> VIDEO_PROMPT`.

Every cinematic decision requires a `semantic_reason`.

No prompt may introduce a new plot fact, relationship fact, world rule, ability, costume identity, prop identity or emotional conclusion that is absent from the authorized source state.

Prompt text is an executable projection, not a source of truth.
