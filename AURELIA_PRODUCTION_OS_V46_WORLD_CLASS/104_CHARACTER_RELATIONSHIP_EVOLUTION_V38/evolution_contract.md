# Evolution Contract

A meaningful character change requires: prior state, pressure, choice/experience, interpretation, consequence, and post-state.

Relationship change requires an observable interaction or established causal event plus interpretation and delta.

State changes are typed as reversible, persistent, or irreversible. The system must never skip directly from `before` to `after` without a transition explanation.

Knowledge firewall: character knowledge is independent from author knowledge, audience knowledge and model knowledge.
