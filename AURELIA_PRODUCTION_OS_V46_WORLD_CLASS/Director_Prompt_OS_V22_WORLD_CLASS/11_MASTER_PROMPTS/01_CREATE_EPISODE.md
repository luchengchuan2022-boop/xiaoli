# TASK PROMPT — CREATE EPISODE

MODE=CREATE

输入：
- current committed state
- canon
- chapter master
- target episode
- constraints
- available assets
- profile

执行：
A. 提取本集唯一核心戏剧任务

C. 设计合法的变化
D. 生成 15s delivery atom
E. 建立 shots / keyframes / performance / camera / audio
F. 编译最终视频 Prompt
G. 生成 START/END
H. 计算 Canon Delta / State Delta
I. 验证
J. 输出 Production Package

不得自动 Commit；Commit 必须通过授权事务。
