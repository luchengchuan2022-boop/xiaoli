# V34 Certification Matrix

CRITICAL: Authority, Canon isolation, state integrity, causal integrity, character agency, relationship continuity, audience fairness, context integrity, production package completeness, provenance, recovery, fail-closed behavior.

QUALITY: originality, thematic depth, emotional precision, cinematic grammar, visual continuity, pacing, novelty, production economy.

A single CRITICAL failure = FAIL. Scores never compensate for a critical failure.

Scale test: same contracts must remain valid at 1, 100, 1600 and 8000+ episodes without requiring full-history context stuffing.
