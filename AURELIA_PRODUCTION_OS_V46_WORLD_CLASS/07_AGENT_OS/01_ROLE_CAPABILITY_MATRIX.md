# ROLE / CAPABILITY MATRIX

Roles may include:
showrunner, story editor, head writer, screenwriter, director, cinematographer, animation supervisor, character animation, background art, VFX, sound, continuity, asset, planner, QA, reliability.

Each role has:
read scopes
proposal scopes
compile scopes
execute scopes
write scopes
commit scopes
release scopes

No role receives authority merely because it is described as "senior".
