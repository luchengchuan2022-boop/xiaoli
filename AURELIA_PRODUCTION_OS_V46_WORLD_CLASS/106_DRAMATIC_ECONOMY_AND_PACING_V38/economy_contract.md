# Dramatic Economy Contract

Track attention, tension, emotion, information, intimacy, mystery, novelty, spectacle, promise pressure and breath as dynamic budgets.

Anti-fatigue rules:
- spectacle must earn semantic cost;
- escalation must change the problem, not merely increase volume;
- repetition must add meaning or be rejected;
- quiet beats must alter emotional or relational state to qualify as productive breath.

Pacing is evaluated across multiple horizons, never from a single 15-second atom alone.
