# V29 Java Contract-First Boundary

Java may implement V29 contracts only after schemas, invariants, acceptance cases and compatibility behavior are fixed.

Required future services include:
- DecisionService
- CandidateEvaluationService
- ConstraintService
- PlanningService
- ConflictQuarantineService
- RepairPlanningService
- ContextPlanningService
- CreativeHealthService

Names are conceptual contracts, not implementation mandates.
