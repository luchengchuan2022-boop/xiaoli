# V39 — Creative Arena

V39 introduces bounded competition between creative candidates. This is not uncontrolled brainstorming and not a popularity vote.

## Candidate lifecycle
`GENERATE -> NORMALIZE -> CONSTRAINT_CHECK -> SIMULATE -> ADVERSARIAL_REVIEW -> SCORE -> PARETO_SET -> SELECT`

## Evaluation axes
Truth, causality, character agency, relationship integrity, audience cognition, dramatic value, thematic value, cinematic potential, continuity, production risk, future option value.

## Red line
A candidate cannot win because it is merely louder, prettier, darker, faster, or more shocking.
