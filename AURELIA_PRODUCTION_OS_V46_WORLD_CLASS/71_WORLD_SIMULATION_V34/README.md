# World Simulation Kernel V34

Model the world as rules + entities + conditions + actions + consequences + traces + time + locality.

A world event is legal only when its preconditions are satisfied by committed state or explicitly authorized creative change.

## Simulation contract
WORLD_STATE(t) + EVENT + RULES → WORLD_STATE(t+1) + OBSERVABLE_TRACES

No simulation result becomes Canon automatically. Simulation produces candidate forecasts/evidence only.

## Rule hierarchy
COSMOLOGY > METAPHYSICS > WORLD_RULE > SYSTEM_RULE > SOCIAL_RULE > LOCAL_RULE > CINEMATIC_CONVENTION

A lower layer cannot silently override a higher layer.

## New-lore gate
Every proposed lore item must declare: source, authority class, dependency set, scope, activation condition, cost, consequence, reversibility, conflict set, retirement policy.

If any critical field is unknown: BLOCKED.
