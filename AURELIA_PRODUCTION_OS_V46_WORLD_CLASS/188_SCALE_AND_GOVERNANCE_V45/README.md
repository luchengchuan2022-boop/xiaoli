# V45 Scale + Governance

The system is designed for 1,600-8,000+ delivery atoms without context stuffing.

## Cross-scale invariants
Atom -> Episode -> Sequence -> Arc -> Season -> Series -> IP.
Lower-scale work may instantiate higher-scale intent but cannot silently redefine higher-scale invariants.

## Health dimensions
character_growth, relationship_accumulation, promise_debt, foreshadowing, world_rule_stability, novelty, repetition, information_balance, emotional_balance, visual_repetition, asset_identity, audience_confusion, future_option_space.

## Governance
Protected semantics have explicit change classes and blast radius. Irreversible/high-blast-radius changes require elevated review and migration proof.

## Studio principle
Prefer the smallest semantic change that produces the required dramatic value. Do not solve a local weakness by creating uncontrolled lore, power, artifact, character, retcon, or relationship jump.
