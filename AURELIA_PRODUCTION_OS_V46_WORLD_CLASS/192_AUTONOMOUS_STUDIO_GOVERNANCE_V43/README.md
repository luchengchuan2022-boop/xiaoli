# V43 — Autonomous Studio Governance

自治系统必须有边界。

## Autonomous scope
可自主：检索、候选生成、镜头表达搜索、非关键表达优化、失败诊断。
不可自主：修改核心 Canon、跨尺度 Retcon、改变关键关系/世界规则、提升模型输出为 Truth、绕过 Gate。

## Stop conditions
关键语义不确定、Authority conflict、Proof gap、future-option collapse、continuity breach、capability mismatch、transaction conflict → STOP / ESCALATE。
