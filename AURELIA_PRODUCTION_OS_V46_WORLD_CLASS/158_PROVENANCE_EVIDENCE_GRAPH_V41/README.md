# V41 Provenance + Evidence Graph

Every consequential claim must point to its origin and every produced artifact must point back to the semantic decisions that created it.

## Proof chain
`source → claim → semantic object → decision → compilation → artifact → observation → evidence → validation → acceptance`.

## Evidence classes
`SOURCE, CANON, STATE, DECISION, COMPILER_TRACE, MODEL_OBSERVATION, HUMAN_REVIEW, AUTOMATED_TEST`.

Evidence supports a claim; evidence itself is not automatically truth.

## Closure
A release is incomplete if required proof links are missing, hashes disagree, or dependency closure is broken.
