# EXECUTABLE SPEC RULES

Every executable contract MUST define:
1. command/input schema
2. output/result schema
3. authority requirements
4. preconditions
5. postconditions
6. state transitions
7. deterministic identifiers
8. idempotency semantics
9. error taxonomy
10. evidence obligations
11. retry/recovery behavior
12. observability fields
13. migration/version behavior
14. contract tests

If one item is intentionally not applicable, the contract must say N/A and why.
