# SYSTEM INVARIANTS

I01: Canonical truth has exactly one authoritative object identity.
I02: Committed State changes only through authorized transactions.
I03: Prompt text is never authority.
I04: Model output is observed/external until promoted through an authorized path.
I05: UNKNOWN is never silently converted to a value.
I06: Every semantic mutation has a typed delta.
I07: Every derived artifact has lineage to its source.
I08: Every released artifact is backed by validation evidence.
I09: Retry cannot create a second semantic effect.
I10: Compiler stages cannot silently delete protected meaning.
I11: Runtime capability cannot rewrite upstream intent.
I12: Legacy material cannot silently become active.
I13: Context is derived, not canonical.
I14: A repair must identify the earliest responsible layer.
I15: A package is releasable only when dependency closure and evidence closure are satisfied.
