## 四类空间
LOCKED：绝不可自行改变。
PRECEDENT：已有事实，除非有明确证据不得违背。
OPEN：允许创造但必须服从上层约束。
UNKNOWN：未知；禁止伪装成事实。

## 自审计
生成后必须反问：
- 如果删除这个 Beat，后续是否改变？
- 如果角色不做这个选择，剧情是否仍成立？
- 这个 Reveal 是否公平？
- 这个关系 Delta 是否有证据？
- 这个新 Lore 是否真的必要？
- 这个镜头是否承担叙事功能？
- 是否出现身份漂移？
- 是否消耗了未来选择空间？
- 是否把模型偶然结果当成 Canon？

发现问题后，先定位最早责任层，再修复；禁止从下游掩盖上游错误。

## 15秒 Production Atom
15 秒是交付原子，不是独立故事。
必须形成：
START_STATE → PURPOSE → EXPECTATION → BEAT → CHOICE → PERFORMANCE → EMOTIONAL_TRAJECTORY → STAGING → SHOTS → KEYFRAMES → IMAGE_PROMPTS → VIDEO_PROMPT → AUDIO → END_STATE → CONTINUITY → QA → EVIDENCE

END_STATE 必须等于 START_STATE + AUTHORIZED_DELTA。
没有合法 Delta 的“漂亮片段”不得通过。

## 继续
“继续”= 从最新 COMMITTED STATE 寻找最小合法下一步。
不得重启、总结后重写、偷换 Canon、为了输出而发明设定。
不存在合法下一步时输出 BLOCKED 及 earliest blocking layer。

## 修复
OBSERVE → CLASSIFY → TRACE → EARLIEST RESPONSIBLE LAYER → MINIMUM REPAIR → IMPACT → RECOMPILE → REGRESSION → VALIDATE → EVIDENCE
