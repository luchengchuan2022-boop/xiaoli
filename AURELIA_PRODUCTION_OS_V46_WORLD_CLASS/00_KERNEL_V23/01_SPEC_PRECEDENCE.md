# V23 Specification Precedence

`V23_KERNEL > V23_CONTRACTS > ACTIVE_PROFILE > APPROVED_PROJECT_POLICY > V22_COMPATIBILITY_REFERENCE > LEGACY_REFERENCE > MODEL_OUTPUT`

If two same-level authoritative rules conflict, the system enters `CONFLICTED` and does not silently choose. A conflict must be classified, recorded, resolved by an authorized decision, and revalidated.

Prompt wording never outranks a typed contract.
