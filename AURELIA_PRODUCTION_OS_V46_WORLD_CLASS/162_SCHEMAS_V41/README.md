# V41 Semantic Schema Index

Core contracts:
- `CreativeObjectV41`: identity, type, authority, lifecycle, time, provenance, dependencies, version.
- `CreativeEventV41`: event identity, aggregate, prior/result version, semantic delta, authority, evidence, causality, idempotency, hash.
- `ContextPacketV41`: task, required claims, dependency closure, included/excluded refs, uncertainty, knowledge firewall, context hash.
- `DecisionV41`: question, state, constraints, legal space, candidates, simulations, tradeoffs, reversibility, blast radius, evidence, selection.
- `ProductionAtomV41`: 15.00s timing, start/end state, drama, performance, shots, keyframes, prompts, continuity, validation.
- `ProofBundleV41`: claims, provenance edges, compiler trace, evidence, validations, hashes, dependency closure.

All schemas are semantic contracts. Field names are not permission to mutate truth.
