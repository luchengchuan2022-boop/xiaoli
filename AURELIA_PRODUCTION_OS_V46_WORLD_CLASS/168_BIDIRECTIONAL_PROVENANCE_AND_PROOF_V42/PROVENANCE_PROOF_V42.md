# BIDIRECTIONAL PROVENANCE & PROOF V42

Every production artifact must be traceable upward and every authoritative change must be traceable downward.

## Upward proof
`15S_ATOM → SHOT → CINEMATIC_INTENT → DRAMATIC_BEAT → CHARACTER/RELATIONSHIP → STORY → WORLD/CANON`

## Downward impact
`CANON_CHANGE → DEPENDENCY_CLOSURE → AFFECTED_STATES → FUTURE_STORY → SEQUENCES → ATOMS → PROMPTS → ASSETS → REPRODUCTION_PLAN`

## Proof closure
A package is proof-complete only when every critical assertion has a source/authority reference, and every critical transformation declares preserved/changed/omitted/introduced semantics.
