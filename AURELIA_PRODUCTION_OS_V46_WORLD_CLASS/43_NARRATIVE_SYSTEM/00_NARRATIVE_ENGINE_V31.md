# Narrative Engine V31

## 1. 单位
Story / Arc / Episode / Scene / Beat / Delivery Atom 必须互相映射，禁止任一层级孤立生成。

## 2. Beat Contract
每个 Beat 至少声明：
- dramatic_purpose
- causal_input
- character_choice
- opposition_or_pressure
- information_change
- emotional_change
- consequence
- future_value
- deletion_cost

## 3. Scene Necessity Test
场景只有在至少一个核心维度产生不可替代价值时才保留：人物、关系、因果、信息、主题、世界、情绪、视觉、未来回收。
若全部为零，FAIL。

## 4. Causal Integrity
结果必须能追溯到此前状态、选择、规则或外部压力。突然发生的重大变化必须有显式来源或标记为待证候选。

## 5. Dramatic Debt
每个未完成承诺、未解释异常、未兑现选择都登记为债务；债务只能被兑现、转化、撤销（带原因）或合法保留，禁止静默遗忘。

## 6. Theme
主题必须通过人物选择与代价被戏剧化。禁止用旁白解释主题代替戏剧行动。

## 7. Anti-Filler
连续 Beats 如果只重复同一信息、同一情绪、同一关系状态且没有新增未来价值，则进入合并/删除候选。
