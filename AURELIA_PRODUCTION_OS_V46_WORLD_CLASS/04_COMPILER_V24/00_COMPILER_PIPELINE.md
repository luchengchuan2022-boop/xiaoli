# V24 Compiler Pipeline

Canonical pipeline:
`LOAD → RESOLVE → CONTEXT_COMPILE → SEMANTIC_COMPILE → DRAMATIC_COMPILE → CINEMATIC_COMPILE → IR_NORMALIZE → CONSTRAINT_COMPILE → PROMPT_AST → CAPABILITY_CHECK → ADAPT → PREFLIGHT → RENDER → EVIDENCE`.

Each stage has explicit input/output contracts, version, loss budget, diagnostics and provenance.
