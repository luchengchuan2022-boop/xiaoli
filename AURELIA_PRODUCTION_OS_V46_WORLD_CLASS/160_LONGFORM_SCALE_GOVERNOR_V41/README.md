# V41 Longform Scale Governor

Designed for 1600–8000+ delivery atoms without requiring the entire history in one context.

Monitor: character arc health, relationship accumulation, promise/debt balance, mystery pressure, reveal timing, world-rule drift, motif lifecycle, novelty, repetition, audience confusion, production debt and future option space.

## Drift budgets
Every major identity domain has a bounded drift budget. Crossing the budget triggers review or repair.

## Scale rule
Longform quality is a property of state architecture, retrieval and causal continuity—not context window size.
