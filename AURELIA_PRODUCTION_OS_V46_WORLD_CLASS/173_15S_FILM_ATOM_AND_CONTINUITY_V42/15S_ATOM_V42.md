# 15 SECOND FILM ATOM V42

A 15-second atom is a delivery unit inside a continuous film, never an isolated content island.

Required:
`START_STATE → PURPOSE → BEAT → CHOICE → EMOTIONAL_TRAJECTORY → AUDIENCE_STATE → PERFORMANCE → STAGING → SHOT_PLAN → KEYFRAMES → IMAGE_PROMPTS → VIDEO_PROMPT → AUDIO → END_STATE → CONTINUITY → QA → EVIDENCE → MANIFEST`.

Hard timing contract: total duration = exactly 15.00 seconds.

`END_STATE = START_STATE + AUTHORIZED_DELTA`.

Every atom must declare carry-in dependencies and carry-out state.
