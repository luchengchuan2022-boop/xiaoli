# 15-SECOND DELIVERY ATOM

The 15-second unit is a delivery boundary inside continuous cinema, not an independent short film.

Required:
start_state
dramatic_objective
beat
attention_plan
performance
shot_plan
timing
end_state
continuity_refs
asset_refs
prompt_ast_ref
validation_ref

Invariant:
END_STATE = START_STATE + AUTHORIZED_DELTA

AUTHORIZED_DELTA may be zero.
