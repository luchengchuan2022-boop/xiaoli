# Trace and Impact Semantics

TRACE_UPSTREAM returns the shortest justified lineage plus optional dependency closure.
TRACE_DOWNSTREAM returns all declared dependents within a scope.
IMPACT_ANALYSIS classifies consequences as INVALIDATED, REQUIRES_RECOMPILE, REQUIRES_REVIEW, RISK_INCREASED, or UNAFFECTED.

A change is not complete until its impact set is evaluated at atom, episode, sequence, arc, season, series and IP horizons where applicable.
