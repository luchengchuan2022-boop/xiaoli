# V23 Production Language

V23 defines a typed language for animation production rather than a collection of prompts.

Core nouns:
`Object, State, Event, Decision, Intent, Context, IR, Asset, Constraint, Evidence, Patch, Task, Transaction, Package, Release`

Core verbs:
`read, infer, propose, compile, render, observe, validate, patch, authorize, apply, commit, release, replay, recover`

A natural-language prompt is a rendering of a typed intent and is never itself the authoritative semantic representation.
