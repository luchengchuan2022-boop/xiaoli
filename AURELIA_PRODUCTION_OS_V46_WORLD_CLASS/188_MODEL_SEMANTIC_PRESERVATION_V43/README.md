# V43 — Model Semantic Preservation Contract

模型适配的目标不是“生成得更好看”，而是尽可能保持源语义。

## Capability negotiation
模型声明：支持/不支持的时长、角色数、镜头语言、参考图、运动复杂度、声音、风格约束、连续性机制。

## Preservation policy
当模型能力不足时：
1. 先降级表达，不改变 Canon；
2. 若无法保持 protected semantics → BLOCK；
3. 不得由模型自行发明补偿剧情。

## Observation
模型输出属于 OBSERVATION，不属于 TRUTH。
