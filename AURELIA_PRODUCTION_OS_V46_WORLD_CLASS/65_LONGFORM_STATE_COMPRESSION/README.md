V33 Longform State Compression & Retrieval

Build minimum sufficient context from structured memory rather than dumping history.

Retrieval priority: authority, causal dependency, unresolved consequence, active promise/debt, character knowledge, relationship state, timeline/spatial continuity, motif relevance, recent evidence, production position.

Each retrieved fact carries provenance, authority, confidence class, temporal scope, and dependency links.

Compression must be loss-aware. If critical semantics cannot be safely compressed, fail closed and request broader retrieval.
