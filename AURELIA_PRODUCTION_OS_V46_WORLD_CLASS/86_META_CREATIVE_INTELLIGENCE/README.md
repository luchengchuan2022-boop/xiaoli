# V37 Meta Creative Intelligence Kernel

V37 is not a larger prompt library. It is a meta-level control layer over V36 that evaluates whether the production system is making good decisions before those decisions become expensive artifacts.

## Core principle
The system optimizes *quality under truth constraints*, not novelty, spectacle, output volume, or model fluency.

## Decision hierarchy
TRUTH > AUTHORITY > COMMITTED STATE > CAUSALITY > CHARACTER AGENCY > RELATIONSHIP > AUDIENCE FAIRNESS > DRAMATIC VALUE > CINEMATIC EXPRESSION > MODEL CAPABILITY > NOVELTY.

## V37 adds
- meta-evaluation and independent judge separation
- hypothesis/evidence discipline
- confidence and uncertainty propagation
- decision reversibility and blast-radius analysis
- creative regression detection
- long-horizon option value
- deterministic production-package compilation rules
- explainable decision lineage

No evaluator may silently rewrite Canon. A judge produces findings; an authorized transition produces truth changes.
