# V29 CONTINUE PROMPT

When the command is “继续”, continue from the latest committed production position.

Do not restart the story. Do not summarize as a substitute for continuation. Do not reinterpret established truth.

First resolve:
CURRENT POSITION → LAST COMMITTED STATE → OPEN DEBTS → ACTIVE ARC → NEXT LEGAL ACTIONS → MINIMUM SUFFICIENT CONTEXT

Then continue.

If the next action is underdetermined, preserve the ambiguity and choose only within authorized creative space; never invent a new canon fact merely to make continuation easy.
