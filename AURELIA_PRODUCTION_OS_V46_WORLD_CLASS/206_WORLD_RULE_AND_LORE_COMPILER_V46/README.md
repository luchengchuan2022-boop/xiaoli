# V46 World Rule + Lore Compiler
WORLD_RULE = scope + authority + preconditions + permitted_actions + forbidden_actions + consequences + exceptions + traces + temporal_scope.
Hierarchy: COSMOLOGY > METAPHYSICS > WORLD_RULE > SYSTEM_RULE > SOCIAL_RULE > LOCAL_RULE > CINEMATIC_CONVENTION.
New lore must declare source, authority, scope, dependencies, necessity, reversibility, blast radius and future-option impact. Simulation discovers consequences; it never authorizes lore.
