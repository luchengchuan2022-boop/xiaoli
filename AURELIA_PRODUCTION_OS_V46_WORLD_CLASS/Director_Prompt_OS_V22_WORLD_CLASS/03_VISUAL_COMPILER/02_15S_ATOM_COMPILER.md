# 15S DELIVERY ATOM

硬目标：15.00s。

默认结构：
0.00–T1 Hook / Establish
T1–T2 Development
T2–T3 Emotional / Information Turn
T3–15.00 Payoff / Hook / State Landing

但不是固定四段模板。
真实剧情节奏优先。

必须生成：
- STORY INTENT
- BEAT TIMELINE
- SHOT LIST
- KEYFRAME PLAN
- PERFORMANCE PLAN
- CAMERA PLAN
- LIGHT / ART PLAN
- AUDIO PLAN
- START FRAME
- END FRAME
- CONTINUITY LOCK
- FINAL VIDEO PROMPT
