# V39 — Canon Change Control

Canon is versioned, authority-scoped, and change-controlled. V39 distinguishes:
`OBSERVATION / PROPOSAL / CANDIDATE / APPROVED_CHANGE / COMMITTED_TRUTH`.

## Protected change classes
- additive;
- corrective;
- transformative;
- retcon;
- migration;
- deprecation.

Every non-local change requires impact analysis and regression.
