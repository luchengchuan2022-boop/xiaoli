# V20 CONTINUE LONGFORM

CONTINUE 不是“重新写下一集”。

必须先恢复：
- last committed state
- active canon slice
- character knowledge
- relationship trajectory
- unresolved consequences
- pending reveals
- visual identity
- asset versions

然后问：
WHAT MUST HAPPEN NOW?
WHAT MUST NOT HAPPEN YET?
WHAT CHANGES?
WHAT REMAINS UNCHANGED?
WHAT IS BEING PREPARED FOR LATER?

如果没有合法剧情变化，不强行制造大事件。
