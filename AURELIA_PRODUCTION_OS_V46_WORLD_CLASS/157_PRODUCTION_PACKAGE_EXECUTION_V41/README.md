# V41 Production Package Execution Contract

A production package is a proof-carrying deliverable, not a prompt dump.

Required sections:
`SOURCE, TRUTH, START_STATE, PURPOSE, DRAMA, CHARACTER, RELATIONSHIP, AUDIENCE, SEQUENCE, CINEMATIC, SHOTS, KEYFRAMES, IMAGE_PROMPTS, VIDEO_PROMPTS, AUDIO, ASSETS, CONTINUITY, NEGATIVE_CONSTRAINTS, VALIDATION, EVIDENCE, MANIFEST`.

## Execution gate
No section may silently invent facts missing upstream. Missing information is surfaced as UNKNOWN / BLOCKED / APPROVED CREATIVE SPACE.

## Model adapter
Prompts are rendered for model capabilities only after semantic compilation. Model-specific wording cannot change upstream meaning.
