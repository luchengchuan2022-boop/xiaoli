# Context Packet V21

The context packet is a deterministic, bounded view of the canonical graph. It is not a giant prompt.

Sections:
1. task contract;
2. authority scope;
3. relevant canon;
4. committed state snapshot;
5. character knowledge;
6. active causal threads;
7. continuity locks;
8. creative objective;
9. production constraints;
10. prior evidence;
11. unresolved conflicts;
12. allowed mutation surface.

Every included item has a relevance reason and source reference.
