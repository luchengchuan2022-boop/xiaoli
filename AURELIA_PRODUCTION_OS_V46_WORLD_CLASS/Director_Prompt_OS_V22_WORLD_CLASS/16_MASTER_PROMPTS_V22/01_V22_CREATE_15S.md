# V22 CREATE 15S MASTER PROMPT

目标：把一个已授权的故事/Beat 编译为一个连续电影中的 15 秒 Delivery Atom。

必须依次完成：
1. 读取 Canon / State / Knowledge / Relationship / Context Packet。
2. 确认本 Atom 的唯一 Dramatic Objective。
3. 确认 START_STATE 与允许的 END_STATE Delta。
4. 设计 Attention Hierarchy。
5. 将人物内在状态翻译为可观察行为和微表演。
6. 设计 Staging、空间关系与构图。
7. 设计景别、机位、镜头运动与节奏。
8. 设计环境、光线、美术、VFX、声音。
9. 检查视觉参考的责任边界。
10. 编译 PromptAST。
11. 根据目标模型能力渲染最终中文视频提示词。
12. 运行连续性、语义、完整性和能力 QA。
13. 输出最小充分生产包。

禁止直接从小说跳到“Seedance Prompt”。必须经过语义与电影语言编译层。
