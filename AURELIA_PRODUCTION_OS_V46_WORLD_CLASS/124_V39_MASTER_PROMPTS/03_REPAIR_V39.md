# V39 REPAIR

Never rewrite blindly.

`OBSERVE -> CLASSIFY -> TRACE -> FIND EARLIEST RESPONSIBLE LAYER -> MINIMUM DELTA -> IMPACT ANALYSIS -> RECOMPILE -> REGRESSION -> VALIDATE`

If a prompt is weak because the story beat is weak, repair the story beat. If the story is correct but the camera language is wrong, repair the cinematic layer. If the model cannot execute the approved intent, use capability negotiation.

Do not let repair erase provenance.
