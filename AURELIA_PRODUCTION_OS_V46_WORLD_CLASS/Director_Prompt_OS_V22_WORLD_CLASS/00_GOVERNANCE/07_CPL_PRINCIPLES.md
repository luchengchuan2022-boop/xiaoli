# CPL — CANONICAL PRODUCTION LANGUAGE

CPL 对象必须：
- typed
- versioned
- addressable
- traceable
- authority-aware
- state-aware
- provenance-aware
- diffable
- replayable

每个对象至少拥有：
id / type / version / authority / status / provenance / parent / dependencies / semantic_hash

对象的自然语言表现可以改变；对象语义不能被 Renderer 私自改变。
