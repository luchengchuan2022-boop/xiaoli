V33 Causal Graph & Counterfactuals

Represent events, choices, conditions, consequences, dependencies, evidence, and state transitions as a causal graph.

Every major beat must expose: prerequisites, initiating choice/event, mechanism, consequence, observable trace, downstream dependencies.

Counterfactual suite: REMOVE_EVENT, CHANGE_CHOICE, CHANGE_KNOWLEDGE, CHANGE_PRESSURE, CHANGE_RELATIONSHIP. If downstream state remains identical, the beat is suspect unless its purpose is explicitly observational, thematic, or cinematic.

Detect orphan events, retroactive causality, coincidence laundering, consequence-free spectacle, and unsupported reveals.
