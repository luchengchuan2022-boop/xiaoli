# V39 — Story Genome Evolution

The Story Genome becomes an explicit evolutionary control system. It protects identity while allowing meaningful change.

`CORE_DNA -> EXPRESSION -> VARIATION -> TEST -> ACCEPT/REJECT -> LINEAGE`

## Genome layers
- immutable identity: central premise, core emotional promise, foundational world axioms;
- protected identity: character essence, relationship thesis, visual grammar, thematic contradiction;
- evolvable identity: motifs, pacing patterns, episode forms, secondary institutions;
- local expression: scene-level inventions and cinematic details.

## Anti-drift test
A candidate is rejected when novelty is purchased by weakening protected identity without an authorized creative decision.

## Evolution rule
Change must be earned by accumulated causality, not by novelty pressure.
