# V24 Canonical Object Model

Canonical Object fields: `object_id, object_type, namespace, schema_version, revision, authority, lifecycle_status, provenance, semantic_hash, parent_refs, dependency_refs, created_by, created_at, valid_from, valid_to, payload`.

Objects are typed, addressable, versioned, diffable, lineage-aware and replayable.
Files and prompts are artifacts derived from objects. They are not canonical truth merely because they exist on disk.
