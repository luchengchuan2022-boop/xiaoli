# AUTONOMOUS REVIEW BOARD V37

## Seats
Story Editor / Head Writer / World Architect / Character Director / Animation Director / Cinematographer / Layout / VFX / Continuity / Production / Audience / Reliability.

## Review protocol
1. Freeze context.
2. State the question.
3. Require each seat to cite evidence.
4. Separate observation from preference.
5. Identify conflicts.
6. Classify conflict: factual / semantic / creative / production / taste.
7. Arbitrate only within legal authority.
8. Produce decision record.

## Important
Multiple agents repeating the same unsupported claim does not increase evidential strength.

## Creative disagreement
Creative disagreement is allowed. Canon disagreement is not resolved by voting; it is resolved by authority and evidence.
