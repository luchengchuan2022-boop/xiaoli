# V30 CREATIVE COGNITION KERNEL

## 目标
把“世界级导演/编剧的判断力”变成可审计的 Production OS 决策语言，而不是继续堆提示词。

## 核心链
PERCEIVE → INTERPRET → INTEND → CHOOSE → CONSEQUENCE → MEANING → NEXT_STATE

任何创作候选必须回答：
1. 观众此刻看见什么？
2. 观众因此推断什么？
3. 角色此刻真正想要什么？
4. 角色为什么只能/更可能做这个选择？
5. 选择造成什么不可逆或可追踪后果？
6. 这一变化如何服务主题、关系、世界或悬念？
7. 下一状态获得了什么新的戏剧可能？

## 禁止
- 只用“好看、震撼、浪漫、电影感”作为决策理由。
- 用新设定掩盖旧戏剧问题。
- 用视觉奇观替代人物选择。
- 用台词解释本应由行为表达的意义。
- 把模型随机性当成创作判断。
