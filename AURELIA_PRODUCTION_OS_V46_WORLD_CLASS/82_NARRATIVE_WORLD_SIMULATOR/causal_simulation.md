# Causal Simulation V35

For every important beat, compute:
- Preconditions
- Initiating cause
- Actor choice
- Mechanism
- Immediate consequence
- Delayed consequence
- Observable trace
- Characters who can know the trace
- Downstream dependencies
- Reversibility

Forbidden: coincidence as a substitute for missing causality; new lore used to rescue a broken plot; consequence-free spectacle.
