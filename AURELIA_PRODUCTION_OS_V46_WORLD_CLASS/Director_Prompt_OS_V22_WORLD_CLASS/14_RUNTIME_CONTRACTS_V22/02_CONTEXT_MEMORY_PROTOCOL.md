# V22 Context & Memory Protocol

Context is a computed packet, not a giant prompt.

## Memory classes

- Canonical Memory — authoritative truth.
- State Memory — committed current state.
- Semantic Memory — relationships, causal graph, motifs, unresolved debts.
- Episodic Memory — prior production episodes and evidence.
- Working Context — task-local material.
- Experimental Memory — proposals and non-committed explorations.

## Retrieval order

`hard dependencies → current state → character knowledge → causal ancestors → unresolved payoff/continuity debt → relevant visual assets → style/profile rules → optional inspiration`

Irrelevant context must be excluded when it increases ambiguity or contradiction risk.
