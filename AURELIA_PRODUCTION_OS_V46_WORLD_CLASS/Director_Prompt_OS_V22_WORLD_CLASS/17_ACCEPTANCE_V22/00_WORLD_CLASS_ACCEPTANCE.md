# V22 World-Class Acceptance Standard

V22 is acceptable only if it can demonstrate, through executable or reviewable test cases:

## Creative
- preserves Canon;
- preserves character identity and knowledge;
- maintains causal and emotional continuity;
- generates non-generic behavior;
- produces cinematic 15-second atoms that connect as one film.

## Compiler
- story meaning survives IR compilation;
- PromptAST is complete;
- adapter limitations are explicit;
- no silent semantic loss occurs.

## Long-form
- context remains bounded and relevant;
- payoff/continuity debt remains traceable;
- continuation does not reset state;
- revisions and forks remain identifiable.

## Reliability
- duplicate events are idempotent;
- replay produces the same committed semantic state;
- crashes do not silently create semantic ambiguity;
- writeback conflicts fail closed.

## QA
- invariants are machine-checkable where possible;
- golden cases detect semantic regression;
- release evidence is complete;
- 1600–8000 episode stress tests have explicit acceptance criteria.
