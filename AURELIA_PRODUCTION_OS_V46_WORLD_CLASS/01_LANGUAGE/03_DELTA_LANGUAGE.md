# SEMANTIC DELTA LANGUAGE

A Semantic Delta is the only legal language for material change.

Required:
delta_id
target_object
operation
before_projection
after_projection
reason
authority
provenance
dependencies
risk
validation_requirements.

Delta categories:
D0 NONE
D1 DERIVATION
D2 PRESENTATION
D3 PRODUCTION
D4 STORY_STATE
D5 CANON
D6 POLICY/SCHEMA.

Higher-impact deltas require stronger authority.
