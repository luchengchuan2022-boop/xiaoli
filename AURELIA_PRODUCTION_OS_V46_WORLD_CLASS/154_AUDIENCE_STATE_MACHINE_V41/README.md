# V41 Audience State Machine

Track the audience separately from characters:
`KNOWN, BELIEVED, SUSPECTED, EXPECTED, MISREAD, PROMISED, FORGOTTEN, EMOTIONALLY_ATTACHED`.

## Reveal contract
Every meaningful reveal declares:
- what the audience knew before
- what was fairly inferable
- what is revealed
- what remains mysterious
- emotional reinterpretation
- future promise created

## Fairness
A twist may surprise without cheating. Hidden information cannot be invented after the fact merely to create shock.
