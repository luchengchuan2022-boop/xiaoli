Stress the system across thousands of episodes for:
- identity continuity;
- relationship continuity;
- knowledge continuity;
- payoff debt;
- asset reuse;
- package size;
- context retrieval;
- event volume;
- recovery;
- semantic regression.

The objective is not merely throughput. It is sustained creative coherence with bounded context and verifiable state.
