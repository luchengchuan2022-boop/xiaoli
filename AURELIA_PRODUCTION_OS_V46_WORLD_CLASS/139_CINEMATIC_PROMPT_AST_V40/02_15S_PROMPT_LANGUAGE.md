# 15s Prompt Language

A production-ready video prompt must encode, in model-operational language:
shot size, camera position, lens/focal impression where relevant, composition, camera movement, subject blocking, character acting, micro-performance, gaze/eye-line, environment behavior, lighting, color, atmosphere, temporal continuity, motion constraints, transition intent and ending state.

Image prompts must specify the exact keyframe intent and identity/continuity locks. Negative constraints must be explicit and semantic, not merely generic quality tags.
