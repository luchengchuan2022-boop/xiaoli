# PRODUCTION COMPILER V37

## Compilation chain
SOURCE → AUTHORITY → STATE → DRAMA → CHARACTER → RELATIONSHIP → AUDIENCE → SEQUENCE → CINEMATIC INTENT → PERFORMANCE → SHOT AST → KEYFRAME AST → IMAGE PROMPT → VIDEO PROMPT → AUDIO → CONTINUITY → QA → EVIDENCE → MANIFEST.

## Every transformation records
PRESERVED / TRANSFORMED / OMITTED / INTRODUCED.

INTRODUCED content must be classified as either:
- derivation permitted by rules, or
- creative addition requiring approval.

## Prompt quality rule
A prompt is successful only if it faithfully expresses the compiled cinematic intent. Prompt richness is not semantic quality.

## Determinism
Given identical authority, committed state, frozen context, compiler version and declared inputs, the semantic package must be reproducible or differences must be explicitly attributed to stochastic generation.

## 15-second compiler contract
The compiler must fit all required beats inside 15.00 seconds, preserve temporal continuity, and expose shot durations summing exactly to 15.00 seconds unless an explicit production contract says otherwise.
