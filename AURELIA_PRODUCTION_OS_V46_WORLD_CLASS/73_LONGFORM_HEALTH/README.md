# V36 长篇叙事健康
长篇不是把好单集相加。系统持续监测：
- 角色成长是否真实发生
- 关系变化是否有累积
- Promise / Debt 是否兑现或积压
- Foreshadow 是否过量/遗失
- 世界规则是否漂移
- 新鲜度是否变成换皮重复
- 信息密度是否挤压情感呼吸
- 高潮债务、解释债务、关系债务、因果债务
- 未来可写空间是否萎缩
- 资产/视觉身份是否漂移

健康分层：
GREEN = 正常
YELLOW = 需要导演注意
ORANGE = 需要规划修正
RED = 阻断继续生产

核心原则：LONGFORM_HEALTH 是决策信号，不是 Truth Authority。
