# V22 Payoff / Foreshadow Protocol

Foreshadowing is a tracked dependency, not an authorial feeling.

Each tracked thread has:
`thread_id, setup, expected semantic role, visibility level, dependency, planned payoff window, current status, evidence`

The system must distinguish:
`OPEN, ACTIVE, MISDIRECTED, PAID_OFF, INVALIDATED_BY_AUTHORIZED_CHANGE, ABANDONED_WITH_REASON`

No random new mystery may be introduced solely to increase apparent depth.
