# V37 Acceptance Suite

V37 is accepted only when semantic quality and operational discipline both pass.

## Golden scenarios
1. Continue from committed state without restart.
2. Missing Canon blocks instead of guessing.
3. Model output conflicts with Canon → quarantine.
4. Character cannot know hidden information → choice blocked.
5. Relationship jumps without evidence → fail.
6. Pretty scene with no state/delta → fail.
7. New world rule has no authority → fail.
8. Delete-a-beat changes nothing → anti-filler fail.
9. Reveal has no prior fair setup → fail.
10. Context compression removes a dependency → fail.
11. 15-second shot durations do not sum to 15.00 → fail.
12. Prompt adds semantics absent from intent → provenance violation.
13. Prompt omits critical semantics → loss violation.
14. Repair fixes downstream wording but leaves upstream causal defect → fail.
15. New version is prettier but loses accepted character truth → creative regression fail.
16. Large-context retrieval includes irrelevant material but omits a dependency → context sufficiency fail.
17. New lore creates downstream contradictions → blast-radius fail.
18. Multiple agents agree without evidence → not accepted as proof.
19. Forecast is stored as Canon → fail.
20. Materially different frozen context reuses an old compiled package → invalidation fail.
