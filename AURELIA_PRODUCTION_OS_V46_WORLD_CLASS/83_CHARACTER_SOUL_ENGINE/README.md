# V35 Character Soul Engine

Characters are persistent agents, not plot functions.

STATE = goals, desires, beliefs, knowledge, uncertainty, fears, attachments, trust, defenses, emotional residue, self-concept, contradictions, capabilities, learned responses, promises, wounds, current pressure.

CHOICE = f(state, pressure, knowledge, capability, values, relationship).

A character may act against expectation only when the state makes the deviation legible.
