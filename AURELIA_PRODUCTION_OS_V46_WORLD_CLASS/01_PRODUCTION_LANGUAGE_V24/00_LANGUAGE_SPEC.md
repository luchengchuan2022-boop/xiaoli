# V24 Production Language Specification

The Production Language is the canonical intermediate language between creative truth and runtime execution.

Core nouns: `OBJECT, STATE, EVENT, TASK, INTENT, BEAT, SHOT, PERFORMANCE, ASSET, CONSTRAINT, IR, PROMPT_AST, EVIDENCE, PATCH, TRANSACTION, PACKAGE, RELEASE`.
Core verbs: `READ, RESOLVE, PROPOSE, COMPILE, RENDER, EXECUTE, OBSERVE, VALIDATE, PATCH, AUTHORIZE, APPLY, COMMIT, RELEASE, REPLAY, RECOVER`.
Every command has identity, authority scope, input revisions, allowed mutation classes, output contract, validation gates and failure policy.
