# SPECIFICATION HIERARCHY

Normative precedence:

1. V25 Kernel
2. V25 Formal Contracts
3. V25 Creative Profile contracts
4. Project-authorized Canon and committed State
5. V24 compatibility material
6. Legacy reference material
7. Model output

A lower layer may propose a change to a higher layer, but cannot commit it.

Every specification document must declare:
- authority class
- status
- owner
- version
- supersedes
- dependencies
- normative/advisory classification

Conflict handling is fail-closed. No document wins merely because it is newer, longer, or more specific.
