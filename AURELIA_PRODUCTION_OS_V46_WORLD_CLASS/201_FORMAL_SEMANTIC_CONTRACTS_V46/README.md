# V46 Formal Semantic Contracts
Every first-class object: IDENTITY + TYPE + AUTHORITY + SCOPE + VALID_TIME + RECORD_TIME + VERSION + LIFECYCLE + PROVENANCE + DEPENDENCIES + HASH + CONFIDENCE.
Contract classes: OBJECT, EDGE, TRANSITION, EVENT, QUERY, CONTEXT, DECISION, PROOF, COMPILATION, OBSERVATION, PACKAGE, TRANSACTION, PROJECTION.
Transition = PRECONDITIONS + PROTECTED_SEMANTICS + AUTHORIZED_DELTA + POSTCONDITIONS + INVARIANTS + EVIDENCE + PROOF + AUTHORIZATION.
UNKNOWN is first-class: unknown != false; missing != approved; inference != truth. Critical unknowns block irreversible decisions.
