# V43 — Prompt AST Formal Grammar

Prompt 不再是自由散文，而是 Production IR 的可验证编译产物。

## AST 顺序
Intent → Audience Focus → Beat → Performance → Blocking → Composition → Shot → Camera → Focus → Light → Color → Environment → VFX → Audio → Keyframe → Motion → Negative Constraints → Continuity Locks。

每个节点必须有 source_ref、semantic_role、required/optional、transformation_status。

## 编译原则
PRESERVED / TRANSFORMED / OMITTED_WITH_REASON / INTRODUCED_AS_CINEMATIC_EXPRESSION。

禁止：凭空增加剧情事实、人物新能力、新关系、新世界规则。
