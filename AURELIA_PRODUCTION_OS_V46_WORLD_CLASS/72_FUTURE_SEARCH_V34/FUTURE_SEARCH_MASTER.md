# 长篇未来搜索主控协议 V34

目标不是寻找“最刺激的下一集”，而是在当前合法状态下寻找“长期价值最高且可生产”的未来路径。

对每个候选评估：
- Canon compatibility
- causal integrity
- character agency
- relationship earnedness
- theme value
- promise/debt impact
- audience cognition
- novelty without drift
- visual opportunity
- production feasibility
- future option value
- reversibility
- regret risk

任何单一分数不得覆盖 Critical Fail。

输出必须包含：candidate_id、why_now、state_delta、future_effects、consumed_assets、new_commitments、risks、rejected_alternatives、director_decision_basis。
