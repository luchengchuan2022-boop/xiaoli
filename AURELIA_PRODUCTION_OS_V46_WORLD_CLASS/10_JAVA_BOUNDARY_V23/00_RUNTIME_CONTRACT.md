# V23 Java Runtime Boundary

Java is an implementation concern, not the source of creative semantics.

The future runtime should implement V23 contracts for:
`ObjectStore, RevisionStore, EventStore, ContextCompiler, TaskOrchestrator, AgentGateway, IRCompiler, PromptRenderer, ModelAdapter, PackageStore, EvidenceStore, Validator, TransactionManager, RecoveryManager, AuditStore`.

No Java class should become an accidental second Canon.
