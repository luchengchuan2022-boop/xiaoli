# V22 Semantic Contract

Semantic equivalence is evaluated before textual similarity.

## Protected semantics

Protected semantics may include plot facts, character identity, motivation, causal order, relationship state, world rules, timeline constraints, visual identity locks, and user-authorized intent.

## Transform classes

- `LOSSLESS`: representation changes only.
- `CONTROLLED_VARIATION`: authorized creative variation within an open space.
- `SEMANTIC_CHANGE`: changes meaning and requires decision authority.
- `CAPABILITY_COMPROMISE`: target adapter cannot fully realize intent.
- `UNKNOWN`: cannot establish equivalence.

No compiler may label a semantic change as lossless merely because the wording looks similar.
