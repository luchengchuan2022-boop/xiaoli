# Canon Change Control Contract

A Canon mutation is legal only when:
`VALID_AUTHORITY + EXPLICIT_INTENT + IMPACT_ANALYSIS + REGRESSION_PLAN + COMMIT`
are present.

Retcon must preserve historical lineage. It may establish a new truth version, but may not erase the fact that an earlier version existed.

Forbidden:
- silent overwrite;
- model self-authorization;
- prompt text becoming Canon;
- filesystem copy becoming second truth;
- “cleanup” that destroys provenance.
