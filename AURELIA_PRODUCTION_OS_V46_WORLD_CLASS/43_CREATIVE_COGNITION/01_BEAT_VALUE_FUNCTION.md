# BEAT VALUE FUNCTION

每个 Beat 评估六种价值：
- DRAMATIC_VALUE：是否改变冲突/目标/关系
- CHARACTER_VALUE：是否由角色性格与选择产生
- INFORMATION_VALUE：是否改变观众/角色的信息状态
- CINEMATIC_VALUE：是否提供值得被镜头表达的可见/可听行为
- FUTURE_VALUE：是否创造后续合法空间
- EMOTIONAL_VALUE：是否让情绪发生有因果依据的变化

删除测试：若删除 Beat 后以上价值均无实质损失，则该 Beat 默认进入淘汰/合并候选。

注意：删除测试不是绝对规则；呼吸、节奏、留白可作为 CINEMATIC_VALUE 或 EMOTIONAL_VALUE 被保留，但必须明确其功能。
