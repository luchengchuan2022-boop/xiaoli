# Director Prompt OS V22 — WORLD CLASS PRODUCTION OS KERNEL

V22 is the authoritative prompt/specification layer for a world-class AI animation Production OS intended for 1600–8000+ episode long-form production with 15-second cinematic delivery atoms and later Java Runtime integration.

## V22 North Star

**ONE MEANING → ONE CANONICAL OBJECT → ONE IDENTITY → ONE AUTHORITY PATH → ONE COMMITTED STATE TRANSITION → ONE SEMANTIC IR → ONE COMPILER PATH → ONE PRODUCTION PACKAGE → ONE EVIDENCE PATH → ONE VERIFIED COMMIT**

Natural-language prompts are renderer output. They are never the source of truth.

## V22 architecture

1. **Creative Truth Kernel** — Canon, approved story decisions, world rules, character/relationship truth, timeline.
2. **Production State Kernel** — revisions, events, tasks, authority, transactions, checkpoints, recovery.
3. **Story & Drama Engine** — causal graph, character state, knowledge, emotion, relationships, information control, payoff debt.
4. **Cinematic Compiler** — DramaticIR → BeatIR → ShotIR → Performance/Staging/Camera/Lighting/Audio/VFX/Asset/Continuity IR → PromptAST.
5. **Agent Orchestration** — bounded specialist roles, evidence handoffs, arbitration, proposal/commit separation.
6. **Context & Memory Engine** — canonical retrieval, relevance scoring, context budgets, snapshots, lineage, anti-drift controls.
7. **Production Package Engine** — dependency graph, artifact lifecycle, manifest, reproducibility, patch sets, release bundle.
8. **Model Adapter Layer** — capability discovery, explicit gaps, deterministic rendering, vendor isolation.
9. **Reliability & QA Kernel** — idempotency, event sourcing, replay, invariant/property/golden/semantic regression tests, release gates.
10. **Creative Profiles** — AURELIA and future IPs specialize the kernel but cannot override it.

## Specification precedence

`V22_KERNEL > V22_CONTRACTS > ACTIVE_CREATIVE_PROFILE > V21_COMPATIBLE_REFERENCE > V20_REFERENCE > LEGACY_REFERENCE > MODEL_OUTPUT`

Conflicts fail closed. Legacy documents are reference material unless explicitly adopted into V22.

## V22 design law

**Do not solve scale by making prompts larger. Solve scale with typed objects, graphs, state, retrieval, compilation, transactions, evidence, and verification.**

## Java boundary

Java is intentionally deferred. V22 defines stable contracts that a later runtime can implement without changing creative semantics.
