# Golden Scenarios V43

1. “继续”不能重启世界。
2. 输入包含与 Canon 冲突的新 lore → quarantine。
3. 模型生成角色新能力 → suggestion only，不进 truth。
4. 关系突然跳跃 → relationship proof fail。
5. 漂亮但无戏剧功能的镜头 → fail。
6. Reveal 缺少 audience preparation → fail。
7. Prompt 想修复上游因果错误 → reject。
8. 同一 transaction 重试 → idempotent。
9. 不同 payload 使用同 key → conflict。
10. Projection hash 不一致 → rebuild required。
11. 15.01 秒 → fail。
12. 模型无法稳定保持 identity lock → capability block。
13. Rollback → compensation event，历史仍存在。
14. 跨尺度修改 IP invariant → escalation。
15. 压缩 context 丢失 dependency → context compile fail。
16. 两个 review seat 冲突 → arbitration，不自动平均。
17. materialization failure after commit → pending recovery，不回滚 truth。
18. replay 与原执行第一次分歧必须可定位。
