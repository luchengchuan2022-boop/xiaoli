# EVENT / STATE / TIME / CAUSALITY V42

V42 separates four dimensions that long-form AI systems commonly collapse.

- EVENT: something asserted to have occurred.
- STATE: the committed semantic condition after authorized events.
- VALID TIME: when the fact is true in story/world time.
- RECORD TIME: when the system recorded the fact.
- CAUSAL EDGE: why one event materially produced another.

## State reconstruction
`STATE(t) = REDUCE(GENESIS, COMMITTED_EVENTS <= t)`

A later event does not erase the historical event. Corrections create explicit supersession/migration records.

## Causality gate
A causal edge requires mechanism, temporal compatibility and evidence or an explicitly authorized world rule. Mere adjacency is insufficient.
