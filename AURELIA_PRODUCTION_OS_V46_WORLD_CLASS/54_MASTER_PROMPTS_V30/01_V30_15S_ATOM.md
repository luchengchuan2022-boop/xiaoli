# V30 15 秒电影原子生产指令

输入：既有状态 + 本次戏剧目的。

必须生成：
START_STATE → DRAMATIC_PURPOSE → BEAT → CHARACTER_CHOICE → EMOTIONAL_TRAJECTORY → AUDIENCE_ATTENTION → STAGING → SHOTS → PERFORMANCE → ENVIRONMENT/LIGHT/SOUND → KEYFRAMES → IMAGE_PROMPTS → VIDEO_PROMPT → END_STATE → CONTINUITY_LOCKS → QA

要求：
- 15 秒是完整生产原子，但不是独立短片。
- END_STATE 必须能由 START_STATE 经授权变化得到。
- 每个镜头有构图、景别、机位、运镜、表演、微表演、背景、美术、光线、声音语义。
- Prompt 必须具体到可执行生产语言。
- 所有负面约束必须防止身份漂移、时间线漂移、空间跳变、风格漂移、廉价 CG 感。
