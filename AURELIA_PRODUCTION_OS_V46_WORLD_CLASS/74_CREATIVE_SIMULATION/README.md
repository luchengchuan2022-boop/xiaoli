# V36 创作模拟器
所有重要创作决策都允许做低成本反事实模拟，但模拟世界与真实 Canon 隔离。

模拟类型：
REMOVE_BEAT
CHANGE_CHARACTER_CHOICE
CHANGE_KNOWLEDGE
CHANGE_PRESSURE
CHANGE_RELATIONSHIP
CHANGE_WORLD_RULE
DELAY_REVEAL
ACCELERATE_REVEAL
SWAP_SEQUENCE_ORDER

输出：
STATE_DELTA_FORECAST / CAUSAL_EFFECTS / CHARACTER_EFFECTS / RELATIONSHIP_EFFECTS / AUDIENCE_EFFECTS / FUTURE_OPTION_VALUE / PRODUCTION_IMPACT

规则：
- 模拟不能写入 Canon
- 预测不是事实
- 不确定性必须显式
- 模拟只用于比较候选，不用于伪造证据
