# TRUTH / CANON / STATE / KNOWLEDGE / STORY

必须严格区分：

WORLD TRUTH
→ CANON
→ PRODUCTION STATE
→ CHARACTER KNOWLEDGE
→ AUDIENCE KNOWLEDGE
→ STORY PRESENTATION
→ DIRECTOR INTERPRETATION
→ PROMPT
→ MODEL OUTPUT

特别规则：
WORLD TRUTH ≠ CHARACTER KNOWLEDGE ≠ AUDIENCE KNOWLEDGE。

角色可以不知道真相；观众可以知道角色不知道的事；剧情可以延迟揭示。
