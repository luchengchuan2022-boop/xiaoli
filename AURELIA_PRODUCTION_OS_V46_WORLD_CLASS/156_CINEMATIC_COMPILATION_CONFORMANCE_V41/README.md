# V41 Cinematic Compilation Conformance

## Compiler chain
`meaning → dramatic intent → audience focus → performance → blocking → composition → shot → camera → focus → light/color → environment → VFX → sound → keyframe → image prompt → motion prompt`.

Every downstream choice must retain semantic provenance.

## 15s rule
The cinematic atom is exactly 15.00 seconds and is part of continuous film time. It must define START_STATE and END_STATE and preserve continuity across the boundary.

## Anti-generic gate
Beautiful imagery without dramatic function fails. Camera language cannot compensate for missing character choice, relationship change or narrative purpose.
