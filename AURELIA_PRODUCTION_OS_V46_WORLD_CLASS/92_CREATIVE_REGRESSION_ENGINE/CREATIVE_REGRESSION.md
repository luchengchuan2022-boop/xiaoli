# CREATIVE REGRESSION ENGINE V37

## Regression dimensions
TRUTH / CAUSALITY / CHARACTER / RELATIONSHIP / AUDIENCE / DRAMA / THEME / CINEMA / CONTINUITY / PRODUCTION / FUTURE_OPTION_VALUE.

## Comparison protocol
CURRENT vs BASELINE must use the same frozen scenario and acceptance criteria. Improvements in one dimension cannot silently hide severe regressions in another.

## Hard regression
Any loss of locked semantics, causality, character knowledge integrity, continuity identity or accepted Canon is a release blocker.

## Soft regression
Lower emotional specificity, weaker scene necessity, repetition, weaker visual grammar or unnecessary production cost may trigger revision depending on thresholds.

## Golden corpus
Maintain representative accepted cases across quiet romance, revelation, conflict, transition, action, exposition, emotional aftermath and 15-second delivery atoms.
