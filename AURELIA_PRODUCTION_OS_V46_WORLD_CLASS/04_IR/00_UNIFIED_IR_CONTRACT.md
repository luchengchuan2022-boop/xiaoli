# UNIFIED PRODUCTION IR V26

V26 defines one semantic-to-production IR family, with typed views rather than competing independent IRs.

Views:
SemanticView
DramaticView
CinematicView
AssetView
AudioView
ContinuityView
ConstraintView
PromptView
ValidationView

All views preserve common object identity and lineage.
A view is not a second source of truth.
