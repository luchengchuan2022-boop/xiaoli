# V43 — 1600–8000+ Scale Governor

长篇规模的核心不是把所有内容塞进上下文，而是让状态可压缩、可索引、可验证、可恢复。

## Health dimensions
character_growth / relationship_accumulation / promises / debts / foreshadowing / world_rule_stability / novelty / repetition / emotional_balance / information_balance / visual_repetition / future_option_space / asset_consistency。

## Drift budget
任何长期漂移必须有阈值、检测、来源定位与修复路径。

## Future option space
规划不能只最大化当前集效果；必须保留未来可写空间。
