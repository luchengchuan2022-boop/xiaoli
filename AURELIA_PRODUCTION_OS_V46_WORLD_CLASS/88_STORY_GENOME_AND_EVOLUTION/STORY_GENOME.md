# STORY GENOME V37

## Genome dimensions
THEME / CENTRAL QUESTION / CHARACTER VALUES / RELATIONSHIP DNA / WORLD RULES / MOTIFS / VISUAL GRAMMAR / EMOTIONAL SIGNATURE / NARRATIVE PROMISES / TABOOS / CORE CONTRADICTIONS.

## Evolution rule
A long series must change without becoming a different series.

Every major evolution is classified as:
- REINFORCEMENT
- DEEPENING
- CONTRAST
- REVERSAL_WITH_PREPARATION
- TRANSFORMATION

A transformation must preserve a traceable relationship to the prior genome.

## Anti-repetition
Similarity is measured semantically, not only lexically. Two scenes are repetitive if they perform substantially the same dramatic function with substantially the same emotional mechanism, even if location, dialogue and visuals differ.

## Anti-novelty-drift
Novelty that cannot be connected to the genome is treated as drift risk, not innovation.
